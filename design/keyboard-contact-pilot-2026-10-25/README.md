# 圈定触点的生图参考 · 2026-10-25

使用内置 `image_gen.imagegen`，全部保留本项目橘猫参考；没有调用外部付费Key。

- `prompt-a.txt`、`prompt-a-correction.txt`：早期文字控制试验，对应attempt01/02。画面较清楚，但琴键/触点仍不准确，未当合格角色接线。
- `guide-a/s/d.svg` 与对应HTML/JPEG：按同一1254方画幅画出8白5黑、圈定目标键、箭头指示左爪；SVG是精确位置示意，JPEG是浏览器渲染参考板。原图不被覆盖。
- `prompt-guided-*.txt`：原图+标注图双参考的试验。
- `prompt-single-guide-*.txt`：只把标注板作为编辑目标，明确擦除红圈/箭头/文字、固定其余身体。效果更接近目标，但仍不能把“爪移动了”当“准确压到指定白键”。
- `guided-s-v2.png`：单参考编辑候选，改善键盘结构；未作为13键最终动画。
- `prompt-body-plate.txt` → `body-plate.png`：保留整猫头/躯干/脚/尾/琴架，清除两前臂/爪和残影的动画底板。公开衍生为`public/character/keyboard-body-v2.jpg`。生成式美术与确定性13键/整臂控制组合，避免将区域同帧冒充逐键演奏。

标注法的关键：一个目标图，一次只指定一只爪一个目标，明确固定其他部位；给出正确键面几何，而不仅写“弹钢琴”。如果输出改键数、镜头、身体或另一爪，应拒绝而不是继续把它切成精灵。

后续可用运行时准确姿态截图作为更完整的几何参考，圈出需要美术润色的区域；不要把文字/圈圈/箭头保留到最终产品。

- `prompt-arm-texture.txt` → `whole-arm-texture.png`：保留原橘猫材质、连续肩至爪、真实透明的单张整臂。alpha bbox为[458,61,349,1130]。运行时用连续网格贴图弯曲，保持每个键的准确触点；不重复铺满纹理，也不拆成多个关节图片。
