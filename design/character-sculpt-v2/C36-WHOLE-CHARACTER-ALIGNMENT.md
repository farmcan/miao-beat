# C36 整体形体候选：仍非原图对齐通过

本轮只以 `public/character/instrument-scenes-v1/guitar/idle.jpg` 为批准外观参考。实际看过原图、公开对照的 C20 彩色全图，以及 C31 整合灰模的正面、脸部和三分之四图。C31 是 C20 头部和 C35 静态接触手的身份精确整合。局部工程合格不等于整体人物相似。

## 先量测再改

手工可见点量测在 `artifacts/character-alignment-c36/reference-landmarks.json`；误差约 2–4 px。H 是耳尖至脚底的图像高度。原图没有已知 3D 相机，所以这里是投影比例比较，不称之为严格相机标定。C36 直接沿用 C31 的正面、脸部与三分之四相机。

| 可见量 | 原图 | C31 | 对本次实现的约束 |
|---|---:|---:|---|
| 头宽 / H | .354 | .360 | 不能泛泛归因为头过窄或任意整体缩头 |
| 眼距 / H | .133 | .139 | 保留已建立眼距，暂不泛缩眼睛 |
| 耳高 / H | .069 | .088 | 耳相对偏高约 28%，本候选压短峰部 22% |
| 最宽腹部平均 y / H，自耳尖向下 | .690 | .732 | 腹体最宽处低约 .042H，本候选上移腹体宽带 |
| 鼻尖相对身体中心偏右 / H | .049 | .021 | 原图的整体侧向神态更强；本候选尚未修正这一差距 |

另外一个不能只靠点比例表示的差距是：原图的中下脸是一块宽、浅、圆方的口鼻区域；C31 的鼻嘴下方更像一个中央圆拱。灰色材质会去掉原图色块的帮助，因此不把颜色块边缘直接当作 3D 断面。

## 单一候选的具体变形

仅在新副本修改 C31 的连续身皮网格，不添加球体、管状手臂或替代猫模型，不修改原始 `.blend`。三个可解释的变形场是：

1. 外耳峰部相对 z=3.18 压短 22%，在耳根平滑归零；中央头顶不动。
2. 腹部最宽带向上移动 .145u，影响 z=.32..1.40；这是局部体块重心修正，不移动琴或扩大身体整体尺度。尾巴外段 x<=-1.40 完全不变，至 x=-1.15 平滑过渡；根部不是全区 bit exact，不把外段锁定写成整尾未变。
3. 鼻嘴下方连续皮肤向共同浅平面 y=-.415 投影 35%，过渡界限为 z=2.40..2.86、abs(x)<=.56；不额外加两侧颊垫，也不膨胀下脸轮廓。已建立的眼、眉、鼻、嘴物件全保持原状。

所有 C35 新手点（`C23 source vertex id == 0`）及双臂/爪的保守宽锁区完全不动。全部 guitar、骨架、root 和其他物件的几何、拓扑、世界变换逐项对照。C37 可继续依原 source ID 身份合入右爪区域，不需要 nearest-point 对应。

## 预渲染基础门检与失败记录

首轮腹部上沿过窄且接近锁区边界，产生真实新增 normal flip（最小 old/new 三角法向 dot=-.9709），渲染前停止。修复是让腹部变形在 z=1.40 前连续归零，扩大衰减宽度；未降低门槛。

第二轮没有翻面，但颊部上沿过陡，最小 dot=.6869，仍未达到本轮保守门槛 .75；扩大局部过渡范围后再次门检。随后 head subset 审计遇到 BMesh lookup table 无效，已补全 lookup table 更新，没有跳过自交检查。三次失败日志留在候选目录。

第一张实际渲图还发现加法式侧颊有两条明显横垫、尾巴被腹部场一起抬起。作者自查拒绝该版，冻结原目录为诊断，不把它交作形体通过。改用共同浅平面投影并给尾部加入局部保护后，输出到 `artifacts/character-alignment-c36/repaired/`。这次修复来自可见反例，不是参数扫描。

最终数值以 `artifacts/character-alignment-c36/repaired/receipt.json` 为准，保存后重开文件验证坐标 exact。局部渲染研究保留原 UV/rest-position 属性作为来源证据，但变形后尚未重新绑定毛发、UV 和动作；不可据此声称彩色或动画交付通过。

## 评审边界

C36 只覆盖以上三处可见形体差。原图的头部侧向态度、脸部神态、软耳工艺感、材质/毛向、琴与姿态整体关系仍需要对实际图逐项审查。保持眼距/琴/手不动是本轮隔离范围，不代表这些方面已经与原图一致。静态候选不证明动作、握持动态、Web、声音或设备体验。

独立角色/轮廓表情、材质/工艺灯光、动作/接触/UI 三方评审必须看原图与当前 C36 的实际正面和裁切，再决定是否存在 P0。候选作者自查不能替代三个独立评审；本文件不作整体人物通过判断。无 public 修改、生产动画扩展、发布或新增费用。
