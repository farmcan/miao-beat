# Miao 整角色视频准备包 · 2026-10-23

**操作只看一份：[跨电脑图生视频操作文档](../../docs/video-animation-handoff.md)。** 其中包含输入图、完整视频提示词、设置、验收与回传要求。

- `01-turnaround.png`：正/侧/背角色参考。
- `02-guitar.png`：先用这张生成一次扫弦。
- `03-keyboard.png`、`04-drums.png`：后续构图备选，尚未做视频验收及跨场景精确对齐。
- `prompts/`：实际生图提示词与视频提示词。
- `provenance.json`：内置image_gen原生成文件名、实际尺寸及SHA；PNG原样复制，未改像素。
- `results/`：用户生成视频后的可选结果目录；不保存凭据。

本包基于本项目早期原创橘猫参考。未复制小红书或Bongo Cat角色美术。GitHub代码许可与示例美术/模型服务产物分别处理。没有新视频、自然度通过或正式站动画已更新的结论；素材不进入public/构建清单。
