# Miao Beat 文案独立审视 · 2026-10-25

范围：只读 `public/index.html`、`public/app.js`，结合当前橘猫角色和网上音乐玩具/猫弹琴语境。仅建议，未改运行代码；没有用户偏好实验或转化数据，不把文案判断写成已验证效果。

## 核心推荐

首页用「给橘猫找点事做。」；副文案用「按键、点琴键都行。先弹两下。」；场景状态用「猫已就位」。乐器下拉优先保留标准名称：钢琴 / 马林巴 / 吉他 / 架子鼓。第一屏只放一处俏皮话，声音状态、加载、报错和按键说明都说人话。

备选：「来都来了，弹两下。」有熟悉的口语节奏，也不需要认一个特定猫梗。它是可测试的创作建议，不是已证实更受欢迎的标题。

## 推荐落到状态与按钮的写法

- 初始声音按钮：「打开声音」；旁边：「点一下，再按 A。」手机显示「点一下，再点琴键。」
- 准备中：「正在装音色 3 / 12」或「正在加载音色 3 / 12」；不要只写「猫在热身」，用户需要知道是否在等资源。
- 就绪：「好了，开弹。」；不要每次按键都重新写一次。
- 加载失败：「音色没加载出来。点“重试声音”。」必要的网络/静音帮助仍放下一句。
- 记谱按钮：「记下这段」；结束：「记好了。回放听听？」
- 导出仍叫「保存演奏文件」，明确是按键文件；不能写「保存音频」「发给朋友听」而实际只给 JSON。
- 跟弹结束：「这一遍结束。换你了。」；谱内保留音名、拍数、当前键和下一键。
- 全屏：「全屏演奏 / 退出演奏」；保持普通功能名。

## 梗的使用与反例

| 不推荐 | 为什么 | 可替代 |
|---|---|---|
| 「哈基米南北绿豆音乐宇宙」 | 把角色身份换成外来标签，首次使用者还不知怎么操作；音乐也没有相应人声音节 | 「来都来了，弹两下。」 |
| 「家人们谁懂啊，猫猫爆改顶流」 | 模仿创作者口吻，却没有值得说的具体事；很快过时 | 「今日主唱：没有。」 |
| 「让每一次敲击治愈灵魂」 | 泛疗愈宣称，任何产品都能替换名词 | 「先听个响。」 |
| 「不是弹错，只是即兴」 | 预先否认用户想认真跟弹的目标，且是常见文案模板 | 「这一遍结束。换你了。」 |
| 「猫替你写出专属神曲」 | 当前是按键触发/记录，不是作曲生成；把作品所有权交给猫 | 「你按键，它就弹。」 |
| 每个音都喊「好耶 / 绝了 / 大师」 | 无差别夸奖使反馈失去可信度，还抢声音注意力 | 当前音名或安静的视觉反馈 |

可借的是“认猫很认真、把小事讲得像大事”的反差，不必搬来一个完整热梗。橘猫可以淡定、略有架势，但不靠嫌弃用户或故意装疯制造个性。

2. [Patatap 原站](https://patatap.com/)：一段说明将触碰、声音与形状运动联系起来。实际读取到原站说明；可借鉴的是一句话讲清可见因果，不复制它的闪光/视觉风格。
3. [Song Maker 官方项目页](https://experiments.withgoogle.com/song-maker)：用制作和分享歌曲的具体任务介绍产品。实际读取官方页；Miao Beat 当前只导出按键 JSON，不能照搬它的链接分享承诺。
4. [Incredibox 简体中文官方页](https://www.incredibox.com/cn/)：围绕拖放角色、制作、录制和分享混音组织说明。实际读取官方中文页；它有网页作品链接，Miao Beat 不能把这个能力写进自己的按钮。
5. [爱鼓捣的邢志磊：《复刻〈猫和老鼠〉弹钢琴》](https://www.bilibili.com/video/BV1y4d1Y7E1F/)：检索摘要显示标题以具体猫弹琴情境建立识别，作者介绍也直接说给孩子和猫做玩具。直接打开遇412，未看完整视频；这里只作为中文标题语境，不引用播放量、不推断文案效果。
6. [三百咪：《还想听什么》](https://www.douyin.com/video/7620876730227579621)：检索摘要可见作者把猫当演奏者与观众说话的短标题；原页打开无可读正文，未观看视频。只借鉴简短的角色内口吻，不把检索评论当用户研究。

以上案例说明存在这些表达方式；第1–8组均为本轮原创建议，受欢迎程度待验证。最便宜的检验是向3–5位未用过的人展示标题+首屏10秒，问“这里能干什么、你准备先点哪里”，再实际按键；不问他们泛泛投票“喜欢哪句”，不把内部选择当用户审美通过。
