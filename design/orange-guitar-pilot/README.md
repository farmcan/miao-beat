# 橘猫吉他：动作纠正小样

2026-10-22。用户明确指出蓝猫审美与手指动作不自然，并认为此前橘猫抱吉他方向更好。本目录保存原参考、完整prompt和素材来源；可试玩源文件位于 `../../public/labs/orange-guitar/`。

使用内置image_gen，以原橘墩设计板为角色和材质参考补一张透明组件图。原PNG直接复制，未编辑像素。实际输出1254×1254 RGBA；组件没有严格落在等分四格内，所以用明确源坐标裁显，未声称生成满足等分规格。身体/头为一层，吉他为一层，两只前臂各一层；这不是完整表情或三乐器资产。

旧版 `pawTransform` 为了把任意爪尖送到任意触点，会改变整前臂比例；点几何对齐不能证明动作自然。本小样让两臂各自只采用一个恒定尺寸。拨弦臂绕固定肩点从-6°扫到9°、短暂停留后收回，快速重击从当前角度续接；不排队、不先跳回起手位，不改动趾线。扶颈爪固定，不靠揉动几个假手指暗示真实和弦把位。身体只给0.55°短反作用，已有动作不随重击反复重置。

真实按键/点按复用既有授权吉他采样和四个简化和弦。首次输入仅准备音色并说明再次点击；准备好后的新输入才同时触发声音和动作。失焦、切后台和减少动态效果会复位；无录制、评分或自动伴奏，也未修改主产品音色和曲谱。

已检查：实际Chrome按1/2/3/4共四击，hits4，非零RMS peak .08311，左右臂回到固定transform，console无warning/error；390×844页面宽390，完整猫与吉他可见，四和弦按钮均82.25×71.5、底部581.70。它证明实际输入、声音与可见短扫弦能工作，不证明人类已认为自然，也不是实体手机听审。

仍有限制：整只曲臂是刚性贴图，不含独立肘腕；身体头部不能独立追光或改表情，闭眼是基态；琴颈爪没有逐指换和弦；只做吉他，没有把这张图拉伸成钢琴/鼓手。原正式首页未被本小样替换。预览发布信息验收后追加。
