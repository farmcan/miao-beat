# Miao Beat 毛绒角色小样

2026-10-22。正面黑毛绒猫、琥珀眼、鼠尾草绿耳机。原始透明 PNG 由内置 imagegen 生成，参考本项目先前生成的角色概念；没有使用 Bongo Cat 图像或外部图库角色。

`plush-atlas-v1.png` 是 1254×1254 RGBA 图，固定 2×2 等格、每格 627×627：左上头与耳机，右上躯干，左下左爪及短前臂，右下右爪及短前臂。PNG 原样保存，没有程序改像素。完整提示词、SHA256、tile/舞台坐标与边缘检查说明见 `manifest.json`。

`../character.js` 的 `mountCharacter(scene)` 将四层放进现有 640×300 SVG；返回 `ready`、`strike(side)`、`destroy()` 和 `atlas`。现有键盘/吉他/架子鼓道具保留；躯干在道具后，爪在道具前，头盖住上臂根部。每只爪能独立打断并重打，单次动作 190ms；持键姿态由原有左右 held 类控制。头有小幅指针跟随与节拍点头，躯干有轻呼吸。眼睛烘焙在头图中，未宣称独立瞳孔绑定或真正 3D 网格。

外部同源 `rig.css` 与图片都加载成功后才隐藏旧 SVG 解剖部件；不需要放宽 CSP 或允许 inline style 元素。加载失败保留原角色。遵守 reduced-motion：停用呼吸、点头、打击与指针运动。

已在实际 Chrome 浅色工作台检查钢琴、吉他与架子鼓组合，正常显示比例下未看到黑底预览中可疑的亮红/黄毛边。其他背景、放大比例与手机帧率未作保证；这仍是可以继续打磨的分层小样。
