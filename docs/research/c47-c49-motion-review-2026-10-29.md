## C47：静态眼神更可读，未见新的镜面 P0

C45r2 face 中两眼主要呈黑色圆片，只有较弱的下缘曲面信息；侧向注意力虽能靠瞳孔位置推知，但神态偏空。C47 的相同脸部机位恢复了蓝色虹膜渐变和小而清楚的上方高光，黑色中心与蓝边更容易分辨。两眼仍共同看向画面右侧，亮点没有成为另一颗瞳孔，也没有把虹膜中心遮成大片白斑。

完整 C47 中，即使脸缩小，侧望和视线方向仍清楚，能读为一只带着注意力抱琴的角色。相比只看 face 近景，这一整帧证据更支持它作为音乐玩具角色的局部可读性。这里的“带着注意力”只描述静态表情，**不是角色已经会随输入响应**。

在本轮实际图像中，没有看到夺目的镜面板、灰色盖片、新增双重眼球轮廓或不对称强反光压倒视线。虹膜下部仍有曲面 / 反射读感，但没有形成新的局部 motion / UI P0。眼白与软睑的整体包裹是否达到原图工艺仍需 craft gate，不能由本角色对固定静态反光的认可代替。

### 对成因的证据边界

C47 保存后 readback 记录全部 mesh / curves 和有效材质节点 / 连接保持，灯的非 transform 参数与 receiver 保持，仅原有两盏 optical area 的 transform 改变。loader probe 则显示：源 C20 灯 local / world 位置正确；尚未 link 的 library donor local 正确但 world 为 identity；link + update 后 world 恢复匹配；C45 继承了零世界位置。该证据支持把丢失灯位置视为本次恢复高光的实际根因，而非继续把黑眼单归因于 cap 曲率压缩。

本角色审阅了 probe，没有独立执行它；C47 是在 C45r2 cap 上重摆灯，**没有“旧压缩 cap + 正确灯”的对照**，因此不能倒推出 C45 曲率恢复必不可少。数值光学方向也不替代实际图像。当前可保留的是这一固定组合在已看机位上的静态效果，不是所有视角或头动中的反光稳定性。

**C47 局部判定：固定机位眼神可读性贡献成立，未见本轮新增镜面 P0；不授予整体 shaded-still 或动态通过。**

## 整体仍 HOLD 的具体原因

**P0-A，耳硬槽及长下脸仍在。** face 图中的深三角耳腔、厚口沿和明显硬转折没有被眼睛变亮消除；嘴到肩之间仍有较长的直立面，与参考迅速融入梨形上身的短脸连接不同。小幅头动与耳动所需的柔软体积基础仍未证明。

**P0-B，右拨弦侧仍是旧动作结构。** 猫自身右侧、画面左侧的肩 / 上臂仍有套接与管段读法；末端大而长的封帽爪用短刻痕表示趾，没有原图丰满短掌缘自然靠弦的明确手势。C49 三分之四也保留这一点。明亮眼神不能使该爪自动变成可演奏结构；尚未制作的新右臂不属于本候选。

**P0-C，平滑表面不能替代短绒身份。** 当前虎斑和橙 / 奶油色保留，但材质读感光滑、色块像表面涂层，未形成参考的连续短毛与嵌入纹理。C49 明确 `skin_bound=false`、groom 仍隐藏，当前没有新表面毛绑定验收。不能把研究中隐藏毛发的彩图当作毛感完成或最终角色通过。

这些仍是对实际整猫的可见差距。整帧含猫、双爪与琴符合内部完整场景审查形式，**不等于艺术交付已获通过**；本轮没有修改 public、实际可玩页或生产。
