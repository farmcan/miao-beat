# MiaoBeat 第二版参考谱：旋律来源与拍长

核验日期：2026-10-22。范围仅 `public/scores.js` 与本文；不引入歌词、伴奏谱、MIDI、原曲录音或歌曲判分。

## 本轮交付

保留 `twinkle`、`birthday`、`painter` 的 id、排列及全部原音符事件。新增四条旋律、两条原创鼓节奏，共九条。默认速度是本项目为入门演奏选择的速度，不冒充原作速度。

所有 `beats` 都以四分音符为 1 拍，`.5` 为半拍，`1.5` 为一拍半。`meter:4` 表示 4/4，`meter:3` 表示 3/4。`phrases` 是乐句而不是必然一小节。`scoreEvents(song,bpm)` 按事件保留原字段，追加连续 `index` 与秒数 `offset`；全曲时长为 `sum(beats) × 60 / bpm`，不含预备拍或采样尾音。

旋律使用 `instruments:['piano','marimba','guitar']`；节奏使用 `kind:'rhythm',instruments:['drums']`，没有伪造的 `note`。鼓节奏事件的 `code` 为单次敲击，`codes` 为同一时刻两次敲击；前者四个事件、后者八个事件。鼓映射 Z=kick、X=snare、C=closed-hat。节奏 pattern 为本项目新写的基本练习，没有采用某首现代歌曲的鼓谱。

每条还包含 `difficulty`、`totalBeats`、按默认 BPM 计算的 `durationSeconds`。`sourceUrl` 指向可追溯资料，不表示下载该网页或其录音的授权。

## 公开古谱与实际采用的层次

只使用年代与谱面能够对应的底层旋律。独立录入单线音序并转调、统一演奏拍长；没有复制扫描版图像、现代排版、现代伴奏、歌词或音频进产品。下面区分历史事实与本项目改编。

### 玛丽小羊：不能把 1830 年直接当今日旋律年代

- 原始资料：[Carmina Yalensia，University of Pittsburgh 馆藏扫描](https://archive.org/details/carminayalensiac00garr)，[可直接核对的完整扫描 PDF](https://upload.wikimedia.org/wikipedia/commons/e/e4/Carmina_Yalensia_-_a_complete_and_accurate_collection_of_Yale_College_songs_-_with_piano_accompaniment_%28IA_carminayalensiac00garr%29.pdf)。本次实际打开本书印刷第 47 页（PDF 零基第 52 页）的 **Good Night** 下半部，核对其 Merrily We Roll Along 旋律。标题页/出版登记页属于十九世纪版本，非现代教学编配。
- 交叉馆藏：[Rochester / Sibley Music Library 的 1876 年 Carmina Collegensia 条目](https://urresearch.rochester.edu/institutionalPublicationPublicView.action?institutionalItemId=24941&versionNumber=1) 明列该藏品为 public domain。它证明历史谱本的年代与馆藏状态；本轮未逐页下载该 16.98 MB 的另一版本，不把它说成实际逐音底稿。
- 今日《玛丽小羊》的常见旋律与 Merrily We Roll Along 相同；不能以 1830 年诗作或 Lowell Mason 的早期另一配曲直接代替旋律证据。产品采用这一底层短调，独立移至 C，并按入门常见的整拍节奏录入八小节。十九世纪 Good Night 扫描有附点/短音、和声和休止，本产品没有声称逐项照录该编配。
- 不采用该书《Mary had a little lamb》标题下的另一首曲调；同名不等于同一旋律。

### 欢乐颂：完整主题，不声称完整第九交响曲

- 权威原作资料：[柏林国家图书馆的第九交响曲手稿专题](https://staatsbibliothek-berlin.de/die-staatsbibliothek/abteilungen/musik/sammlungen/bestaende/l-van-beethoven-9-sinfonie/ueber-die-9-sinfonie/) 记录 1824 年总谱与 1824-05-07 首演。[数字影像说明](https://staatsbibliothek-berlin.de/die-staatsbibliothek/abteilungen/musik/sammlungen/bestaende/l-van-beethoven-9-sinfonie/digitale-abbildungen) 区分手稿、誊清与初版。
- [IMSLP 原作条目](https://imslp.org/wiki/Symphony_No.9,_Op.125_(Beethoven,_Ludwig_van)) 列 1824 手稿、1826 Schott 初版及 public-domain 状态；同页也有现代编配和各自许可，不能整页一概复用。
- 本项目独立录入第四乐章 Joy 主题的常见十六小节单线，D 大调移为 C 大调。保留主题的半拍及附点节奏；不复制现代钢琴左右手编配、现代中文歌词、录音。名称和说明均限制为“主题”。本轮未下载 1.5 GB 手稿逐页比对；不声称数字原典级校勘。

### 月光下：法国传统童谣，不是德彪西作品

- 原始古谱：[Vieilles chansons pour les petits enfants，Project Gutenberg #42711](https://www.gutenberg.org/ebooks/42711)。电子版说明原图来自 Library of Congress，音乐另有电子转录。本次实际查看[印刷第 6 页原始扫描](https://www.gutenberg.org/cache/epub/42711/images/page-6.jpg) 的 **CHANT** 单线；不复制其钢琴声部或现代转录文件。
- 历史交叉资料：[Weckerlin 1870，Chansons et rondes enfantines，32–33 页](https://fr.wikisource.org/wiki/Au_clair_de_la_lune_%28Weckerlin_1870%29)。只用于核对古谱旋律与年代，不把 Wikisource 现代正文的 CC BY-SA 许可混作整个项目许可。
- 采用古谱 G 大调旋律向下大二度，成为 F 大调，范围 C4–A4。该旋律没有使用第四级 B♭，所以实际所有音都在白键上。不能因为全部白键便误标成 C 大调。
- 原谱乐句末的休止并入前音时值，作为本项目连续长音参考：保留总拍数与下句开始位置，但不冒充原谱的逐音时值原样。未新增 rest 事件或改变播放器接口。没有完整词曲复制，也没有调用历史或现代录音。

### 两只老虎：明确单八度改编

- 同一古谱集 [#42711](https://www.gutenberg.org/ebooks/42711) 收录 **Frère Jacques**。本次实际查看[印刷第 19 页](https://www.gutenberg.org/cache/epub/42711/images/page-19.jpg) 的结尾与轮唱声部；来源是传统法国曲调，不使用现代中文歌词。
- 常见 C 调单线范围 G3–A4，超过 C4–C5 的现有一八度键盘。任意整体转调都不能把十四个半音的跨度塞入十二个半音。
- 本项目只把末句的两个 G3 升至 G4，其他音高关系与乐句保持；用标题“单八度版”和描述明说。它是完整八小节的轻量改编，不是声称原版音域本来就适配。没有悄悄折叠音高，也不要求扩张当前键盘。

## 为什么没有加入几个看似方便的版本

- 1879 [The Baby’s Bouquet](https://www.gutenberg.org/ebooks/25432) 的 [London Bridge 原谱](https://www.gutenberg.org/cache/epub/25432/images/londonbridge.jpg) 是 6/8 拍变体，和今天常见课堂短谱不完全相同。当前接口/UI 的 `meter` 是每小节四分音符拍数，本轮不把 6/8 伪装成 3/4。
- 同书 [Hot Cross Buns 原谱](https://www.gutenberg.org/cache/epub/25432/images/hotcrossbunsmusic.jpg) 首音组为 D5–D4–G4，与常见三音 E–D–C 教学版不同。没有用“同名古曲”替未核对的现代音序背书。
- 上述版本的发现不等于那些常见旋律受限或不存在公共领域来源；只是本轮没有完成足以直接入库的逐谱匹配。

## 旧曲保留的事实边界

`painter` 仍是七个音、八拍的“开头”，不是全曲。旧研究 [scores.md](./scores.md) 已记录来源署名与缺少完整许可结论。本轮没有补齐权利证据，因此没有扩写、复制现代伴奏或改名“完整公共领域粉刷匠”；“只用开头”本身也不是取得版权许可的证明。

`birthday` 音符/时长不变，新增 `pickupBeats:1` 标明开头两个 C 共占一拍弱起。跟弹预备拍应为 `meter - pickupBeats = 2` 拍，使首个 C 落第三拍，下一音组的 D 落下小节第一拍；预备拍不计入 24 拍旋律时长，由主 Agent 接入调度。

旧文案把 B♭4 当成降 Si、C5 当高 Do，容易把固定 C 键位数字和 F 大调首调混淆；现说明直接写实际音名。建议 UI 对非 C 调优先展示 `key.sub` 的实际音名，再展示按键；若做真正首调数字，需按每首 tonic 计算，F 大调的 C 是 5、B♭ 是 4，不能沿用键面 C 调数字。本轮不修改 app 或绑定。

## 许可边界

新增曲调有十九世纪或更早公开谱本证据，采用其底层旋律及本项目独立单线转调/节奏适配，不采用现代新增表达。这是本次选材依据，不是把“熟悉”“免费可看”当作公共领域判断。Project Gutenberg 对其电子版的使用有条款和地域提示，Wikisource 正文也有自己的许可；本项目没有把这些页面、排版文件或录音重新打包。

本表不扩展任何采样包的许可。钢琴、马林巴、吉他、鼓的声音仍按既有逐文件 sample manifest 与许可声明独立处理。现代歌词、具体编配与录音需要各自授权。

## 验证记录

已用 Node 直接导入 `scores.js` / `bindings.js`，对全部九条执行：

1. 原前三 id/顺序不变；新旋律的每个音都能在 `MELODY` 解析，新鼓事件的每个 `code` 都能在 `DRUMS` 解析。
2. 每个 `beats > 0`，每个 offset 严格递增；末事件 offset + duration 与 `durationSeconds` 误差 < 1e-10。
3. 新增旋律每行分别 8/16/16/8 拍，新增节奏每行四拍；总拍数与上表一致。无越出 C4–C5 的新旋律音。

这验证数据及时间算术，不冒充浏览器实际演奏、人体听审或产品上线验收。原 core test 的 melody-only 检查需要由主 Agent 按本轮节奏谱接口扩充；本次按文件边界没有改测试文件。
