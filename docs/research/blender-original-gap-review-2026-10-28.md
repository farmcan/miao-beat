# Blender 首版与原橘猫的视觉差距评审 · 2026-10-28

本轮只做对照、质量判断和下一步计划，不修改模型或公开页面。用户已明确否决当前 Blender 版本粗糙、与原图差距过大；它不能被称为合格角色交付，也不能把“真实 3D 渲染 / IK 长度稳定 / 能点击播放”当成视觉通过。

## 对照对象与证据边界

已实际打开并查看两幅本地图片：

- **目标原图**：`public/character/instrument-scenes-v1/manifest.json` → `modes.guitar.frames.idle` → `public/character/instrument-scenes-v1/guitar/idle.jpg`。原图为 1254×1254，完整橘猫抱古典吉他。
- **被否决版本**：`public/labs/blender-guitar/poster.webp`，640×640，Blender 测试页静帧。

以下对比是这两幅实际可见图片的视觉评审；不根据“Blender”“毛绒”等文件名推断完成度。只有一张目标机位图，背面形状、真实骨架、毛长及材质参数仍未知，不能声称已恢复原角色三维设定。

## 结论

当前版本换掉了原角色的主要识别特征。原图的主形是**宽、沉、柔软的大梨形身体，配相对较小的圆方头和几乎藏在肚子下的短脚**；测试版是**大球头、竖直窄躯干、分节腿足和鼓出的肩肘**。即使把动作调顺、提高到 4K/更多 samples，仍是另一只造型明显简化的猫。

下一步应先重建一张与原图足够一致的静态角色镜头，过静帧门槛后再绑定与动画。现程序堆叠几何不宜作为最终角色网格继续局部磨光。

## 可以复用什么；哪些必须重建

**可复用的技术基础**：Blender 环境、批量渲染/完整画面导出、固定机位组织、整体帧图集播放、真实按键与声音连接、录制导出、解析两骨 IK 的算法与长度审计、琴弦接触间隙审计、品位与六弦的参数化构造。它们证明的是工具/控制链路有基础，不证明角色美术合格。

**需要重建或重新美术定稿**：身体与头的主比例、圆方脸/耳壳/面颊、眼眶眼睑眉嘴、肩肘腕掌一体蒙皮、短腿小脚、皮毛/颜色分区与条纹、琴与身体的尺度和抱持姿态、匹配原图的镜头/灯光。当前程序球体和粗曲线可留作碰撞/节奏灰盒，不能作为最终网格逐处贴补。

**更多 samples / 更高分辨率不能修复**：错误轮廓、头身比、球形脸、鼓眼与呆视、粗管手臂、几何接缝、大脚、小而过横的琴、云斑木纹、缺少毛层、角色与原图气质不一致。采样只处理积分噪声，分辨率只增加像素，不提供造型设计。

## 先验收静帧，再做动作

### Gate 0：锁定参考和比例定义

以原图为唯一主目标，对两幅图在同样的方形画布上标记：耳尖到足底的角色高度、排除尾/手臂/乐器后的最大腹宽、排除耳/胡须的头宽、双眼中心/眼白宽、脚高、琴沿长轴的总长、指板投影角度。标注和数值应实际完成后再报告；本评审没有把目测写成精确量测。

比例差控制在原图标注值约 ±5% 可以作为初步诊断线，**不是主观审美通过的替代**。来源只有单机位，无法核实的背面形体必须明确列为新设计。

### Gate 1：灰模、轮廓与接合

先交同机位 1024 方形灰模静帧及 128px 缩略黑色轮廓。要求仍能读出原图的大梨形身体、较小圆方头、短腿小脚、大而斜抱的琴；肩肘腕掌不能显出独立球或管段。全图与头/肩肘/爪琴三个近景同时检查，不因远看能遮住接缝就通过。

此门未过，不制作完整动画、不加高密毛、不渲染大量动作帧。

### Gate 2：着色静帧与角色辨识

同机位、同裁切对照原图；查看整图、脸、毛绒边缘、爪与琴四个视图。要求表情/注视方向、暖橘与奶油配色、表面条纹、短绒轮廓、细木纹和轻柔地面影子都具体接近目标。眼白不能成为突出的白玻璃球，奶油肚不能过曝为纯白，原图没有的拼装关节不能靠材料隐藏。

需要用户对**这张静帧**明确表示方向可接受；在用户已否决粗糙版之后，不再把“工具跑通”包装成完成角色交付。用户未接受静帧时，只报告差距和下一步，不能批量扩到其他乐器。

### Gate 3：短动作与交互

只在 Gate 2 通过后，先做一个单次拨弦的 0.4–0.6 秒动作。检查正常速度、半速、关键接触帧和连续重复；猫脸、身体比例、脚底位置与琴不能变。右爪接触弦一次后离弦回收；骨长稳定、表面不穿琴、体积不过度伸缩。左手保持可信抓握。

然后再验证网页单击、按住、连续快按，以及导出视频的实际编码帧。正确输入计数、恒定 IK 长度与接触间隙数值仍只作辅助证据，不替代观看。

## 后续克制动作分层：精致优先，按顺序加

| 层级 | 动作 | 与原图身份的联系 / 约束 |
|---|---|---|
| L0：演奏主体，必须先成立 | 右爪短促触弦、肩肘腕连贯跟随、先离弦再回收；左爪稳定握颈，双脚承重。 | 保留原图短厚前臂与圆爪，不以整张猫平移/旋转冒充弹奏，不排队多演几下。 |
| L1：目光和眼睑 | 演奏前目光轻注意琴/画面右侧；慢段偶尔放松眨眼，快速段保持稳定注视点。 | 原图两眼一致望右、宽眉和小笑嘴是识别点，不能每个按键都眼球跳动或夸张眨眼。 |
| L2：呼吸与轻微头部 | 很小的胸腹呼吸；拨弦后的头部响应略滞后于手，幅度小且不是每音必点头。 | 原图身体低而稳，呼吸不改变腹部主轮廓；不能靠大幅前后摇摆制造“自然”。 |
| L3：耳与尾 | 偶尔一只耳的轻转；尾尖低幅、慢速跟随身体状态，不逐拍抽动。 | 原图耳厚、尾短粗且有重量，不能像细天线/软橡皮尾巴；动画发生后仍保留完整角色轮廓。 |
| L4：轻受力与次级毛发 | 掌部细小受力压缩、毛尖的极轻滞后，仅在主要运动/材质成立后加。 | 不用夸张挤压、弹簧尾和大幅毛浪掩盖错误接触或粗糙模型。 |

先把 L0 做对，再逐层开关对照；每加一层都必须能关闭，确认它帮助读懂演奏而非增加忙乱。精致静帧没有过门槛时，L1–L4 全部延后。
