# 第一声与首屏层次调整 · 2026-10-22

范围：原有音乐玩具的文案、控件顺序和声音准备提示；不增加乐器、评分、账号或上传。角色美术及接触动作由本轮另一部分单独实现，本文不将界面调整称为角色动画验收。

## 依据

只读观察改版前正式页，真实浏览器为1280×720 CSS视口：猫舞台 y223–463，乐器栏 y464–533，口袋谱 y533–634，琴键 y681–803；声音入口 y943–1005，在首屏之外。源码中首次按键会准备音色后直接返回；此前没有明确说明需要再按一次。这是“第一下没有响”的可解释来源，并非人类听感或设备延迟测量。

沿用已有研究：Bongo Cat 的输入与爪子因果联系；Patatap 的短反馈与可打断；Ableton 的先动手再解释。没有新的增长或留存数据，不把这些借鉴等同于 Miao Beat 的效果已获验证。

## 已实现

- 标题改为“随手一弹，猫就来劲。”副文“按个键，给今天配点声音。不会乐器，也能开场。”舞台未弹奏时写“第一声，交给你”，固定说明改为“你的现场”，避免待机就显示演奏中。
- 常规页将声音入口放在乐器栏之后，随后直接是琴键/鼓垫，口袋谱与跟弹仍保留在下方。桌面舞台压至210px；720px以下170px；480px以下136px。保留现有琴键宽度、触控尺寸和横向滑动。
- 全屏演奏采用明确的视觉顺序，将口袋谱/时间线恢复到琴键之前，并将声音说明放到琴键之后，保留原来的短横屏练习空间。
- 冷启动按键立即说明音色准备状态；准备好后明确提示“再按一下”。加载中发生的旧按键不排队、不补播、不写成录制事件。失焦后加载结束也不会迟到发声，界面退出loading状态。
- “导出 JSON”改为“保存演奏文件”；文件仍是原有本地事件JSON，格式与隐私语义保持一致。
