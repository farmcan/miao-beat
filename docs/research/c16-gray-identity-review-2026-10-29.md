# C16r2 静态掌腕：独立身份／轮廓评审

2026-10-29；非 builder。实际打开原图 `public/character/instrument-scenes-v1/guitar/idle.jpg`、C16r2 的 `gray-front.png`、`gray-three-quarter.png`、`gray-grip-inside.png`、`diagnostic-volume-source-inside.png`，并对照 C11r2 inside、C15r2 3/4；读取 C16 README 和 `handoff-manifest.json`。未修改模型、Cloudflare或Git。

**结论：掌腕静态窄关仍失败。** C15长棒／躯干尖鳍已经消失，较短的弯臂与躯干轮廓恢复，这些改善有效；但掌后宽圆垫的双层读感仍是 P0，不能进入颜色或动作。

| 项目 | 独立实看判断 |
| --- | --- |
| C15长直棒前臂／尖鳍 | **这两项回归解除。** 当前3/4中前臂不再是横跨掌后的长直圆棒；躯干连接处没有先前明显下探的三角鳍。回到原弯臂是有价值的方向，不应为修腕重新拉出整条新棒臂。 |
| **掌后宽圆垫，P0保留** | 3/4整帧与inside仍清楚读成前方圆掌、后方宽圆盘／杯垫；下方外轮廓在掌底后又鼓出第二道圆弧，掌侧也存在前后层次的转折。比C13薄楔更软、更连续，却没有成为一个自然短厚掌腕体积。正面被掌和琴颈遮住部分，不代表该问题消失。 |
| 前臂／短掌身份 | 胖短趾、圆掌和弯臂总体仍像同一猫爪，没有换成写实人手或细长爪甲。**未另判前臂整体比例P0**；当前主要阻塞是掌根与宽臂的组合轮廓。掌面仍偏竖长、趾根并列较齐，属P1：原图先读成紧凑圆爪、再看到短趾分缝，当前趾与掌的独立读感较强。 |
| **P1：体素细节** | inside可见趾间细台阶／锯齿与掌面低频竖向起伏；保留短趾本身不等于细节完整。不得用加毛遮住，或以平均残差小宣布原形完全保持。 |

来源色显示圆掌／趾为橙，后圆垫主要落在紫色替换／混合区并接灰色原体积。**r2没有第三个蓝色附加腕体积**，不能把可见双层形状误写成“还留着C11 collar”或独立肢体。贡献场颜色不是语义解剖／蒙皮分割；它只帮助定位当前过渡的形状。其确切成因仍可能同时涉及掌根朝向、宽臂截面与窄带插值，未做反事实验证，不把其中任一项写成已证唯一原因。

原图只有一个可见抱琴视角。它支持短圆爪和自然腕掌的身份目标，不能提供精确后腕坐标；本评审使用3/4检查当前模型自身的双圆盘／杯垫读感，不要求未提供的原背面形状。

下一方法应先统一掌根方向、内部掌体与实际前臂轴／截面，再做过渡；不继续仅换平滑核或加一层遮缝。这是下一验证假设，不是已成功方案。保留本轮修复的弯臂和躯干轮廓，冻结当前失败证据。

single closed mesh、腕patch零自交／翻面只支持对应几何检查，不抵消可见P0；截面闭环也不等于语义腕口认证。接触／相对侧承托交独立contact角色，未以有限ray命中数、负gap或miss判握持成功。体素重建后旧UV／groom／shape绑定仍失效。

**仅静态评审。** 没有实际眨眼、头动、curl、触弦短片或网页输入，动态全部未验。其他拨弦爪、头耳与整体美术状态保留，不因本窄关解除C15两项回归而称完整角色B/C通过。
