## P0 · 左手指板穿插，握颈关系不成立

证据最明确的是两个 `*-left-hand-fix1.png`：画面中央约 x=580–640、y=570–650（1200×1200 图像坐标）有一块灰色 / 橘色手指表面出现在棕色指板内部，周围仍可见棕指板、白色品丝和纵向弦；白弦继续跨过这块肉色表面。它不是从琴颈侧边自然进入并落在弦上的完整指腹轮廓，视觉上呈现从指板中冒出的局部肉块。原色和暖色完全重现，不能归为肤色或阴影。

同时，主要几枚手指块位于颈后 / 颈上缘，掌与腕从下方承托，但没有可读的、连续的指尖绕到弦面接触关系。当前不能把“手放在琴颈附近”签成握颈成功；即便不从单张裁切定量推断穿透深度，现有呈现已经足以构成 P0 视觉接触失败。

拇指：可见上方圆形 / 长形手指块，但这些视角不能独立确认哪个表面是拇指、是否确实接住琴颈背面、是否与前方指腹形成对向夹持。不得写成“拇指已贴颈后通过”，也不应把不可见直接说成缺拇指。当前结论是 **拇指有效支撑未证明**。

## P0 · 右手未形成轻悬 / 拨弦接触，掌指关系失配

两个 `*-right-hand-fix1.png` 中，宽大掌背遮住音孔主要区域，三根长指向琴桥与面板下方垂落，接近盖住琴桥一侧。整体读成大手摊压 / 挂在面板前方，没有一处清楚的“短指尖轻悬在弦面、准备拨弦”接触焦点；拇指也没有形成可辨认的独立拨弦方向。全身正面和 3/4 同样可见这一问题，不能靠只展示全身把近景失败隐藏掉。

这组图可以证明右手位于琴前，但不能证明所谓 3mm 悬空。弦被掌挡住本身并不能证明所有遮挡处穿模，因此本文**不把每一条弦消失都判为几何穿透**；已能确定的 P0 是指定悬弦 / 拨弦状态没有成立，而且这个宽掌长指的起始形态缺少下一步微小拨弦的清楚路径。若直接动画化，容易先表现为整掌扫过琴面或从面板中抽出，必须先解决静态接触。

## 可动性与不能推出的结果

保留了原 rig、原臂长与成熟琴几何，属于继续修静态接触的可用基础。**骨长没变、控制器存在、GLB 六弦完整都不等于动作通过。** 这轮没有动画、手指轨迹、抬指 / 压弦、拇指稳定性、拨弦前后两个姿态、弦振动或关节极限测试，也没有浏览器音画交互。

当前 P0 下不允许直接扩动作。下一道合格证据仍是同一静态全身图 + 正 / 3/4 + 左右手近图，左手能看清拇指颈后与前侧指腹的夹持、指板上无肉色穿透，右手在弦面上有清楚接触 / 微小悬空并留出可读拨弦路径；修复应由唯一姿态 builder 在原 rig / 原臂长与整琴统一比例约束内处理。本文不授权额外迭代，不自行改动任何场景，也不对已用完的一次针对修复额度作延展。
