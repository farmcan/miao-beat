# Miao reuse static-hold fix1：独立 craft gate

日期：2026-10-29。Reviewer 为非 builder 的独立材料 / 工艺 / 灯光评审。检查齐备后的原色与暖色同姿态版本；没有改图、建模、改 pose、重渲或执行动画。

## 判定：FAIL

**本次整合 shaded-static gate 失败，动画与美术交付继续阻挡。** 存在两项 P0：面部眼区伪影、握颈接触处破碎的手指 / 指板可见关系。不能因 Wing It! Cat 与 Classic Guitar 各自素材库评审通过，或“完整猫和琴已经同帧”，把本次整合判为通过。暖色配色没有修复 P0。

本结论是当前适配 / 整合画面的判定，不是指称上游电影原资产存在相同问题。用户接受成熟 stock 猫换色，因此没有以“穿工装、戴护目镜、不等于原 Miao 梨形”作为本次失败理由；真正阻挡的是当前实际画面的精致度、面部完整性和掌指接触。

## 材料、工艺与灯光的其余观察

1. **面部表达未完成（P1，且与 P0 同时存在）。** Sealed Mouth 后鼻子以下几乎是整片无嘴线的浅色面，无法读出原图的温和笑意；正视的大蓝眼与绷平眉形偏呆视。脸部近图还显示眼圈、鼻子、眉毛与下颌轮廓的多边形分段，额头有放射状弱折面。用户允许换 stock 角色，但不等于允许丢失精致表情。不是“提高 samples 即可证明解决”的问题。
2. **掌指与琴的工艺层级不协调（P1；握颈处另有上表 P0）。** 拨弦手三根向下手指体积完整，但近图指端轮廓明显折线，手背表面略有条带感；大手盖过音孔和多根弦，无法直接看清可用的拨弦接触点。琴有细密真弦和复杂琴头，猫手却以较粗的表面与接触展示，视觉精度不匹配。没有要求重造手；问题在当前姿态、显示质量和接触取景没有把成熟手的优势兑现。
3. **暖色是颜色变化，尚非精致 look-dev（P1）。** 暖色脸变为橙棕 / 奶油，方向可以继续参考；工装却压得接近黑色，袖口与躯干细节、臂体层次难辨。琴面仍很亮黄，侧板较灰，音孔纹样偏软，琴头可见上游品牌字样。原图有温暖柔和但清楚的体积转折、短绒感与木材层级；本图虽保留 3D 体积，却是相对平、硬边的不同材质观感。不能称已达到原图工艺水准。
4. **灯光与落地感不足（P1）。** 原色 / 暖色都置于灰底，脚下没有清楚承重阴影，整体像悬空；暖色下身与背景 / 袖口分离较弱，脸与琴面占据大部分亮度。材质判断的照明证据尚不足：当前可看见基本形状，但没有把面部圆润度、布料和毛色的细节清楚呈现。

完整猫、手臂、琴在全身图里共同出现，是制作约束的一项成立；全身图没有裁断完整人物。它只证明“同帧”，不证明自然握持或美术质量。当前琴相对大头偏小、抱持靠近胸下，也是整体观感与原图不同的地方，但不凭此单独判 P0。

## 下一步与停止条件

本次 fix1 不放行动作、录制演奏或生产替换。现行 reuse plan 已限制一个主方案加一次有依据的修复；这次是 fix1，仍未过关，**不得自行开启 fix2 / fix3 几何参数实验链来延长当前失败方案**。应把这两项 P0 和本地证据作为当前适配失败记录，回到其他成熟模板的筛选，或由主任务在用户授权边界内明确采用另一条已验证的现成兼容路径。

无论下一候选是哪一个，恢复标准都必须来自新候选自身：清楚无伪影的脸、自然完整指腹与琴颈关系、双爪接触、正面 / 3Q 与对应裁切，以及目标材质光照下的三角色复评。不能用此前候选库 PASS、作者成片、原生成功打开或其他文件成功渲染代替此次恢复。

动作 clip、按键交互、自然眨眼 / 视线响应和录制导出均未在本评审验证，不适用；没有通过静态门便不能推断其可用。本地报告属于内部证据，任务的公开摘要 / 部分失败事件由主任务写入既有 Seed 状态机制，明确“静态适配失败，未交付新美术”。

### 直接可见的恢复与限制

- 两图原来画面左眼七点钟附近的面色三角均已不见，蓝色眼面和黑色眼缘在该处连续；不是换镜头藏住旧问题，正面和 3Q 都能观察到原出错区域。此项 P0 可记为**限定镜头的恢复**。
- 嘴唇轮廓、口腔和牙齿重新可见，鼻下整片无嘴的状态已解除。它是原生张嘴基线恢复，不等于原图温和笑意、侧看视线或最终表情工艺已通过。
- 当前恢复图是原色灰猫的脸部镜头；暖色完整猫 + 琴、双爪接触、全身落地感、近景材质与所有其他镜头没有因这两张图获得恢复。手部仅在下缘局部出现，不能用于复核握颈 P0，也不能替代完整角色同帧验收。
- 仍可看到较硬的眼圈、眉毛和嘴缘轮廓，以及额头细微放射状折面；这些既有 craft P1 没有被本次基线恢复自动关闭。

### 独立诊断对成因归属的影响

只读 diagnostic 记录 fix1 的 `Sealed Mouth=true`，对应原生 MouthMask / UVDeform / PetsMouth 等驱动切换；恢复 receipt 记录将其恢复为 `false`，恢复源 `FK-Head` / 双侧 pupil，Quality 3 → 1，并在每次 render 前显式使 camera helper Euler 与实际 camera Euler 一致。恢复后两个镜头 XYZ axis error 均为 0。原 diagnostic 的 helper / camera 世界旋转差约 1.0886 rad，说明此前“driver valid”并不能证明兼容补丁与原意等效。

这些证据足以支持**当前适配中存在 rig 使用 / 相机兼容处理错误，并可通过保留 stock 几何的有限纠错恢复面部基线**。它们不是逐变量消融实验，不能把眼三角唯一归因于某一个开关，也不能声称完整上游 shader / rig 全部兼容。receipt 记录没有执行上游嵌入脚本、autoexec 关闭，原下载和冻结 fix1 的 SHA 在恢复前后不变。

### 当前规则与后续范围的明确修正

本次用户替换后的 AGENTS.md 明确允许：主方案与一次修复失败后先冻结、独立诊断；对于已证明的 rig 开关、兼容补丁或测量接触使用错误，可以作不重建 stock 几何的有边界纠正。因此，前文“失败后应换模板”的历史下一步不是当前无条件要求；不能因我们误用专业资产而直接判上游猫质量不合格。

允许的恢复仍须以具体错误证据为限，不允许继续自造头体手、无限参数实验或跳过三角色 gate。**此次只关闭已实际观察到的脸部三角 P0，并记录嘴部可见性恢复；手部接触的 FAIL 不变，不放行动作、不签最终 Miao 美术、不进行生产替换。** 后续若修接触，须由新完整画面、双爪裁切和对应测量独立复核；整体恢复不能由脸部成功代替。

## 追加建议：接触 P0 清除后的最小 look-dev（只读，未执行）

本 reviewer 再次实际比较原图 `public/character/instrument-scenes-v1/guitar/idle.jpg`、作者预览 `artifacts/upstream-cat-candidates/scout-a/studio-cat-preview.png` 与本机原色 `artifacts/miao-reuse-v1/compat/wingit-received-materials-color.png`，同时参照上面已查看的暖色 / 琴近图。原图可借鉴的是柔和但清楚的体积、干净的材质层级与落地感；作者预览证明成熟 stock 自己的卡通材质语言同样可成立。**不要求把 stock 强制改成原图 plush，不重造头体手，也不追不存在的电影原 shader 还原。**

建议限定三项，在同一已通过接触的静态 pose 和镜头上逐项比较：

1. **场景与主辅光：** 在脚底高度加入浅中性 / 微暖的普通承影地面，背景保持干净浅色；沿用现有大面积灯，适度增加主光方向感、保留较弱柔和补光，让脸颊、手背和袖口有可见的明暗转折，同时脚底有自然接触影。原色 native 的灰底没有可读地面，像悬空；不能靠一味提环境亮度把体积照平，也不能用强 AO / 暗影遮住掌指交点。判断点是脚落地、脸手有体积、接触仍清晰可审。
2. **工装配色 / 明度：** 保留原生服装与贴图，用原色可读的蓝色或较浅蓝灰作基线，只微调服装色与粗糙度；暖色试验把 `cat.suit_blue` 等纹理逐通道相乘后压得过黑，应先恢复领口、袖口、口袋和前臂层次，而非为整图加曝光。脸 / 手可以温暖，但不必增加毛发或改几何来证明精致。判断点是全身尺寸仍能分清布料结构、手与袖口，眼鼻仍为视觉重点。
3. **琴的局部表面：** 保留完整琴几何、弦和品丝，仅在确认 UV 区域 / 节点通道后将侧背板调为适量暖棕、减弱灰亮大反射，必要时提高该区域粗糙度 / 降低错误金属感；不要全局调琴材质而一起压暗金属弦或漂白面板。配合已有无品牌 / 音孔细节的局部贴图修整要求，在最终像素大小审查。判断点是木侧仍有漆面光泽但不似灰金属，琴面纹理不过黄、不过软，手指 / 银弦分离清楚。

以上是候选调整建议，未编辑、未渲染、未验证效果，**不构成艺术 PASS，也不改变现存接触 P0 与整体 FAIL**。接触未通过前不得先以更讨好的光照、遮挡或材质替代问题修正；调整后仍须同机位完整猫 + 琴与脸 / 双爪裁切的三角色静态复评。
