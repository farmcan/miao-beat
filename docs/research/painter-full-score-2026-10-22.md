# 完整《粉刷匠》谱源核验

2026-10-22。只研究，未改运行时、未复制完整旋律或歌词进公开数据、未联系外人或购买曲谱。

## 结论

**完整单线在技术上可以适配现有键盘；准确出版谱已实际核对，公开内置的许可仍为 unknown。** 不能仅因“波兰儿歌”“免费展示”或某仓库代码 MIT，就声称底层曲调可公开再分发。当前只有七音的 `painter` 不算全曲。

## 实际核对的主谱

[湖南文艺资源域公开 PDF](https://hnwy-ecs-backup.oss-cn-beijing.aliyuncs.com/uploads/20190627/2732d7a19671431fbffeb610ee481a4c.pdf)，139 页，实际下载完成为 5,623,051 bytes；用 PDF 解析工具取印刷第 125 页（PDF 零基索引 124），渲染后通过图像工具看了整页，未只凭搜索摘要推音序。

原 PDF SHA-256：`66a453ff1f728292103b78c06874efb4e0f7a837894b19c3714a4126803bdc56`。

该页标题《粉刷匠》，署名为：波兰佳基洛夫斯卡词、列申斯卡曲、谢坚强配伴奏。它是有署名的出版谱，而不是本轮已经证实的无名传统旋律。谱页只供本机核对，没有复制进产品或公开素材目录。

| 项目 | 实际谱面 |
|---|---|
| 调性 | G 大调，一个升号 |
| 拍号/速度 | 2/4；“中速”，未印具体 BPM |
| 完整结构 | 钢琴前奏 4 小节；其后声部 16 小节，一段体，4 句 × 4 小节 |
| 声部总长 | 32 个四分音符拍，不含 8 拍前奏 |
| 音域 | G4–D5，即主音至上方纯五度 |
| 音符/节奏 | 48 个主旋律发音事件；以八分音符、四分音符、二分音符为主 |
| 末小节 | 主音四分音符，随后四分休止；不是持续二分音符 |
| 弱起 | 无；去掉前奏后旋律从强拍开始 |

[湖北省教育考试院 2017 年学前教育技能考纲](https://www.hbea.edu.cn/files/2016-10-2/2017%E5%B9%B4%E6%B9%96%E5%8C%97%E7%9C%81%E6%8A%80%E8%83%BD%E9%AB%98%E8%80%83%E6%8A%80%E8%83%BD%E8%80%83%E8%AF%95%E5%A4%A7%E7%BA%B2%EF%BC%88%E5%AD%A6%E5%89%8D%E6%95%99%E8%82%B2%EF%BC%89.pdf) 的官方索引提取也列 C 大调、2/4、一段体、16 小节；该 PDF 直接访问超时，因此仅作为调性可有转调版本的交叉线索，不冒充又看过一遍全谱。

## 如何适配本站

将已核 G 调声部整体降低纯五度，范围成为 C4–G4，只需五个白键。结构不必八度折叠，不需扩展键盘。默认 108 BPM 可作为产品练习速度，但不能写成原作精确速度；32 拍在该速度约 17.778 秒，不含预备拍/尾音。

现七音 prefix 的前六音各一拍、末音两拍，共八拍；对照原谱相同七音仅四拍。因此当前版本属于时值放大的慢练片段，不能直接将整拍数组续上并称原时值全曲。

准确接入应补 2/4 节拍器并用四分拍记时；若只支持 4/4，也可明确做“每两小节合成一小节的练习重编”，保持四分拍速度，不把重编冒充原谱小节。最后一拍休止要有明确处理：引擎若只接受可发音事件，不能偷偷播放一个假音。可扩展 rest 事件；若把末音延成两拍，须标连续长音练习版。

## 作者与许可：已知和缺口

中文谱的词曲署名可核；[香港考评局中央音乐学院考级目录](https://www.hkeaa.edu.hk/DocLibrary/ipe/ccompractical/ccm_title_singing.pdf) 的检索摘要也列相近中文署名和曹永声译配，但本次直接请求 403，没有声称看过该目录 PDF 的完整正文。

[波兰歌曲数字图书馆](https://bibliotekapiosenki.pl/osoby/Leszczynska_Franciszka) 有作曲家 Franciszka Leszczyńska（1914–1987）传记，且记载她创作大量儿童歌曲；然而本轮**没有核到把这个拉丁姓名、波兰原曲题名与本页旋律唯一连起来的原出版记录**。不能仅凭“列申斯卡”的姓音译便填入生卒、推算该曲已过期。词作者的准确拉丁拼写、原出版年及当前授权主体同样保留 unknown。

主谱 PDF 未见覆盖公开网页展示、转调后机器演奏和下发谱数据的开放许可声明。伴奏又有单独编配署名，本项目即使只取旋律，也需要核实底层作品依据；本轮不采用该钢琴伴奏或中文歌词。

## 一个真实代码候选及淘汰理由

[niuwa-jun/piano-app](https://github.com/niuwa-jun/piano-app)，本次实测 HEAD 为 `77d49d15eb7f4652df7824d6ca9faa757938eb5e`。README 声明代码 MIT、采样另遵 Salamander 的 CC-BY；未找到该底层曲调的单独许可。实际读取该 SHA 的 `index.html` 第 281–283 行：`painter.seq` 只有两行、24 个音符 token，和已核完整声部的 48 个发音事件不符。

因此它证明“已有网页钢琴与教学接口可参考”，**不证明完整《粉刷匠》已得到许可、也不是可直接 import 的准确全曲数据**。没有复制其音序或采样，没有拿 README 曲目列表代替真实代码核查。

## 最小可行路径

1. 已拿到准确完整谱面，可以先完成内部结构核对与适配设计；不再盲搜“免费 MIDI”补曲。
2. 如需公开内置，补齐该底层曲调/所用版本的开放许可或权利依据后，独立录入单线并以 16 小节、32 拍、48 发音和末拍休止验收；不要复制现代钢琴伴奏。
3. 在许可来源未齐时，可提供此公开出版资料的原站查看入口、保留用户本地录制/导入回放；这不等于已完成公开内置全曲。现有已核公共领域短谱可继续用于即时演奏，但不能换名充当《粉刷匠》。

当前交付是准确性研究与可执行适配方案，未宣称谱数据已入库、许可证已取得或全曲已上线。
