# 社区角色参考：可爱与酷怎么同时成立

日期：2026-10-22（Asia/Shanghai）。性质：窄范围、只读社区作品研究。实际通过 Chrome 打开作者原帖、查看作品画面；不凭搜索标题、点赞数或收藏数决定审美。没有下载、复制、改编或部署第三方角色，没有完整通看所有动画循环，更没有验证这些作品给 Miao Beat 带来转化。

## 建议

优先验证“软圆身体＋有一点自己的脾气＋演奏时投入”。可爱可来自体积、短肢和不完美；酷可来自专注、克制与偶尔爆发，不必主要靠低眉、尖脸、墨镜或皮衣。此前墨爪等原创方向仍是候选，不因交叉评审胜出便认定用户已接受。

## 1. BallCat：软圆身体与坏坏的喜感

- 原作者：Sung-jae KIM；[原帖 Cat Character Stop Motion Animation](https://www.behance.net/gallery/80894109/Cat-Character-Stop-Motion-Animation)。
- 实际可见：黑色梨形黏土身体、短白手脚、小红鼻、细尾巴。原帖角色表情板包含半垂眼、露牙、困倦、惊讶、抬手等状态。身体大团块很软，但表情并不永远乖巧。
- 设计判断：本组最接近可爱与酷同时成立；圆厚轮廓负责亲近感，半垂眼、嘴和姿势反差负责自己的脾气。这是主观设计判断，不是用户偏好数据。
- Miao 可借：少细节的大块轮廓；平时松弛，真实击打时突然利落，结束再收住。保持一只猫的身份，不照抄其脸、黑白红组合与具体造型。
- 权利：画面标有 © BallCat；本轮未找到角色、照片或影片可再分发许可，不能作为现成游戏资产导入。
- 验证边界：看了原帖实际图像与表情板，没有完整看完其定格影片，也没有检验实时输入控制能力。

## 2. Lofi cat：音乐气质来自注意力

- 原作者：Lidds_Design；[原帖 Lofi cat animation](https://dribbble.com/shots/11263372-Lofi-cat-animation)。
- 实际可见：深灰团状猫、黄色眼睛、细长上翘尾巴、红领结、柔粉背景；身体低伏，注意地上正在播放音乐的手机。
- 设计判断：音乐感先来自“它在听”，不是佩戴乐器道具。酷感较温和，偏松弛、专注；不能将它包装成强烈的摇滚气质。
- Miao 可借：演奏时身体和脸转向共同注意的乐器；尾巴与身体构成轮廓节奏；减少始终正面看用户的商品摆拍感。材质不必更复杂。
- 权利：作者说明明确署 © @Lidds_Design；未见开放再利用许可，只借设计方法。
- 验证边界：作者称其为循环动画；本轮实际查看了原帖画面，未完整评测循环、节奏或自然度。

## 3. Cat interaction：可复用技术研究入口

- 原作者：Elvin_R；[原帖 Cat interaction](https://rive.app/community/files/11564-22141-cat-interaction/)。
- 实际可见：米色简化圆猫、点眼、短脚和上翘大尾巴；原帖展示 Click / Unclick、mouse tracking 等输入以及预览入口。
- Miao 可借：研究少量明确输入如何连接状态与回应。现有 2.5D 仍可先做相同状态小样，不因看到 Rive 例子立即更换引擎。
- 审美边界：偏乖巧、简单，适合作技术参考，不将它当“酷”的标杆。

## 最小验证顺序

1. 先用原创素材或现有组件做同音色、同八音片段，包含等待、左右交替、同侧重击、停止和收尾；不同时换音色、背景和机位。
2. 在实际产品尺寸下比较：无乐器时是否仍有身份；输入时是否看得见猫的回应；它像在听和弹，还是只在晃。
3. 如果半垂眼让人觉得冷淡，回到更开放的中性脸；如果缩小时只剩大黑团，先修明度与轮廓；如果演奏时看不到角色，先修布局。
4. 这几项未过，不扩展大量表情、真 3D 或长视频。没有经人类试玩的偏好数据时，结论仍是待验证假设。
