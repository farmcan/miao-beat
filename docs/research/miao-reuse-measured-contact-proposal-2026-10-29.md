# 一次有界接触纠错 · 实测目标方案

**交给唯一 pose builder 的一组数值初值，不是接触 PASS。到此停止只读摆位搜索。** 只允许原 rig 关节姿态、整琴刚体变换；不拉臂、不缩手、不另造琴。专业猫 / 琴素材本身的质量与本次短臂能否完成接触是两个问题。此前 fix1 的 FAIL 仍有效。

本轮 Blender 3.6.23 `--factory-startup --disable-autoexec` 只读取 fix1，未分配 object / pose transform、未保存 blend、未渲染。源码 `design/miao-reuse-v1/scripts/measure_contact_targets.py`，主数据 `artifacts/miao-reuse-v1/contact-proposal/measured-contact-targets.json`；原 scene 前后 SHA256 均为 `82369d247be9711392882c75b1107f8f3d6acb43e601935ac21f32395fd25e24`。

## 先纠正测量口径

- 原 diagnostic 的左中指骨端 signed distance **−3.463mm** 确实在板内；骨端不是皮肤。本轮取 evaluated `GEO-hands` 上 distal bone weight≥.35、骨局部 Y≥.6L 的顶端皮肤样本，左食指半径 90 分位约 **16.64mm**，左中指 17.80mm，右拇指 16.09mm。骨端贴弦绝不等于指腹落弦。
- GLB 的同一根弦有四个 UV / normal seam 分岛。原 24 条长窄片按**源横轴 X 的中心距离≤2mm**聚类，本轮两截面都得到 **6组×4片**，再对每根管状弦正面 ray-cast；不是 24 根弦。以主 JSON 的六项 surface list 为准。
- 拇指近端 mid-pad 另取骨局部 .3L–.8L 的实际皮肤，左 Thumb1 半径约 **21.65mm**。不能把这个粗拇指末端强塞到食指背后的同一点；用其近端肉垫支撑颈背，末端沿颈后放松。

## 只采用这组整琴刚体变换

整琴 **uniform scale=.70**，比 fix1 .50 大 40%；颈轴 **T=(.96592581,0,.25881904)**，即仅向上 15°；横轴 **C=(.25881904,0,−.96592581)**，正面法线 **N=(0,−1,0)**；location **(−.34314516,−.26864243,.205)m**。对应 Blender 原始 +Z 颈轴的 Y rotation 为75°，其余角为0；角度由目标轴定义，不是任意 Euler 试值。完整 world matrix 在 JSON。

实际顶点 bbox min **(−.35028559,−.31738600,.08862846)**，max **(.40950558,−.21989885,.43027908)** m。整琴宽 .75979m / 原猫头 mesh 宽 .64223m≈**1.183**；不再是比头还窄的小琴。大琴也不自动代表比例美观，仍须一次全身图复评。

真实工装检查包含 evaluated `GEO-body`、pockets、zipper_line、zipper_handle、collar。先算 Y=−.22 的靠身候选，1,435 个采样顶点进入工装前 / 后包络，最大46.64mm，明确拒绝；仅按最大深度再加2mm做一次解析外移，得到上述 Y=−.268642。外移后10,018个有工装投影交集的顶点中 **0个在包络内**；头部测试没有投影候选点。**这是顶点包络检查，未覆盖三角相交、手皮肤或所有衣物细节，不能冒称完整碰撞通过。** 琴背也不是已证实贴腹承托。

另外已拒绝“Y=−.22、Z=.295”的上移靠身提案：工装47.37mm穿入，外移后仍有头部42.81mm交叠。记录保留在 `rejected-raised-contact-targets.json`；不可照用。

左食指目标对应源 distal bone-local pad proxy **q=(0,.8L,+.01634953)**，不是 bone tail。其局部 frame 由目标轴 `X=−T、Y=−C、Z=−N` 和原 rig 相对 wrist 的真实 roll 反推；因此 pad 的 +Z 指向琴，指段沿颈横向弯持。左腕先由真实相对 frame 计算，再检查原臂 reach。

左拇指颈背**皮肤目标** **(.12747447,−.29669958,.33106095)**，实际颈背法线约 **(.04120654,.99659741,−.07138304)**。近端 pad 轴心 proxy **(.12836640,−.27512807,.32951584)**，离虚拟 Thumb1 根部19.13mm，约其原长30.43mm的63%；用 Thumb1 近端肉垫接住颈后。不要把 Thumb2 尾骨瞄准这个点，否则会要求极端折叠。上述半径偏移只是初值，最后仍看真实皮肤。

右腕通过“原 Thumb2 相对手的皮肤 proxy 向量→准备点”的向量对齐，再围绕该向量做**一次解析 twist**得到，不是凭角度枚举。保持轻握 / 单拇指准备，掌心与其余三指收在上缘外侧；JSON 给出的 thumb pad 朝琴方向 dot≈.860。右腕中心距实际琴侧最近约13.63mm且在外侧，但腕皮肤更厚，**仍有皮肤碰琴风险**；不能把中心在外就当整腕通过。

## 一次 builder 闭环与停止条件

1. **只设一次**上述整琴矩阵与两手 world matrix，IK stretch=0，保原骨长。左右腕到肩重新实测；右手任何所需额外外移若超过7.16mm可达余量，直接停止，不拉臂。
2. 手 frame 之后，对**每根手指分别**做有界局部 X 两关节数值 IK，不再复制统一 curl。食指皮肤落弦、拇指近端 pad 颈背、右 thumb 3mm hover 为主约束；右 Index / Middle / Pinky 的骨尾目标收向各自 carpal 与掌内侧，目的是形成松拳，不是压孔。允许的起始域可取非拇指 X1∈[0°,100°]、X2∈[0°,110°]；拇指按原 roll 用窄域 X1∈[−60°,60°]、X2∈[−60°,75°]。这些是**求解边界，不是指定角**。某关节已有约束更严则遵其约束；不为达点解除限位。
3. 采用有限差分1°测每指 `d(actual skin point)/dθ`，damped least squares / coordinate descent 均可：每步≤5°，每指≤15次更新，无改善3步停止。每次必须重取 evaluated skin，不能只解 bone tail。若两个 X 自由度不足，判该方案不成立，不继续扩角域、再转琴或开参数网格。
4. 数值关只允许：左目标 pad 与弦面 gap 0–0.5mm、拇指近端颈背 gap 0–1mm；左手其余皮肤不得进入板体 / 弦下；掌避开板。右 thumb gap 1–3mm，其他指与琴至少2mm、掌不盖主音孔；腕 / 指 / 袖口实际皮肤无内部相交。任一 P0 / 不可达 / 皮肤穿入即停在 FAIL，**不渲假装通过**。
5. 数值关通过才输出**一次**相同 pose 的 front / 3q / 左右手 crop。至少看见一枚左指腹落弦、拇指颈后与掌间隙，右 thumb 独立准备且长指收掌。独立三角色复评有 P0仍 FAIL；不追加第二轮参数搜索，不扩动作。

轴向依据也已测出：在旧 fix1 frame，`FK-Index2.L` 正X每1°使骨尾向琴内约0.314mm，`FK-Middle2.L` 约0.414mm；`FK-Middle1.R` 约1.107mm。说明“继续加正 curl”会加深旧问题。**这些符号仅对旧 frame 的瞬时导数成立，换 wrist frame 必须重测**。完整16个关节的 world local-X / Jacobian 在 `read-only-contact-measurements.json`。

本方案只提供一组通过原臂 reach 的初值与明确停机条件；没有证明手皮肤约束可同时满足，没有新动作。若这次有限 IK 仍不能满足，就报告现成猫的当前手形 / 短臂与此握持目标不匹配，交主任务决定，不把失败归咎于专业模型质量。
