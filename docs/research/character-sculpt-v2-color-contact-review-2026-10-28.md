# 连续曲面 v2 C2 彩色静帧：抱琴与可动画性独立评审

2026-10-28。角色：抱琴／接触准备／关节与后续体验。评审者未建造本候选（另行制作的 Modelr 试验不是本次对象）。实际查看主参考 `public/character/instrument-scenes-v1/guitar/idle.jpg`，以及 `artifacts/character-sculpt-v2-color-2/color-front.png`、`color-three-quarter.png`。同时参照本人的 r3→r6 灰模评审和已实际读取的 r6 几何审计，绝不把 r6 有限探针扩大成 C2 全碰撞通过。

## 结论

**本职责范围没有发现 r3 两项“无握持／触弦爪结构”的 P0 在 C2 复发。** 橘色猫爪与深色指板、浅色面板分开后，握琴爪上方的短趾、内侧留空及拨弦爪的圆钝边缘／两条指沟仍可辨认，肩腕是完整连接的猫体表面。相较原图，爪仍更像长手套，握琴指根有明显团块，拨弦爪偏长、扁且顺滑；这些是未消失的 P1，不能写成“原图级自然抱琴已实现”。

这是 **C 静帧的接触／可动画性角色评审**，不是整轮美术通过。身份／材质角色仍可因自己看到的 P0 否决全关；头眼动作、拨弦、连续按键、音频同步、网页性能和录制导出没有本候选证据，全部尚未验证。

## 接触证据的范围

r6 `geometry-audit.json` 的30个指定探针中7个命中被分类为爪的表面区间，未有弦深度落入这7个区间；对应最近后边界到弦深度差约0.05774～0.15121场景单位，支持的是**准备姿态**。该审计依赖排除琴后躯干的启发式分类，没有覆盖整张琴面、握琴爪、groom实际体积或任何动作；也未在本次重新生成 C2 几何审计。因此这里不写 C2 精确接触、全身无碰撞或可变形网格已通过。

## 下一步最多三项

1. 由身份／材质评审决定 C 关是否还有 P0；本报告不越权用“爪能看懂”放行整只角色。保留爪紧凑度和指根团块这两个 P1，给同机位爪近景收敛。
2. C 通过后只做三个完整场景姿态：准备、单次触弦、离弦。确认哪个圆钝爪缘是主要触点、一次输入只有一次主要越弦，回程绕开弦和琴面；再做局部蒙皮／极限弯腕检查。完整角色、相连双爪和琴仍在同一帧。
3. 这三姿态通过后再比较 D0 中手动作与眨眼／视线时钟组合。快速输入不逐次重置头，不补演积压动作；新网页和导出需重新实测，旧原型测试不继承为本候选通过。

## C4 追加复评：腕部亮弧是静态连续性 P0，暂不扩动作

本次重新实际打开原图与 `artifacts/character-sculpt-v2-color-4/color-front.png`、`color-three-quarter.png`。未参与root资产建模；本次不评本人制作的Modelr候选。C4颜色／条纹／木纹更清楚，但本职责新增一个不能忽略的可见静态阻塞。

### P0：拨弦前臂的亮奶油弧造成腕部接片感

正视图画面左侧前臂下段，有一条很细、明亮的奶油色弧／斜线，从靠近琴上缘处一路跨过橘色毛皮到爪下缘；三分之四视图同一位置呈更明显的弧形，像手套袖口或单独爪子接到前臂。原图对应区域是连续的橘毛和柔和体积过渡，没有这条亮弧。用户曾明确反对分离手臂的效果，因此即便实际网格连通，这条线也会使随后腕部动作更像接片在动，损害其想要的完整自然猫爪。

**可见缺陷成立，原因仍未知。** 两张成片不足以判断它是毛色／UV问题、表面法线／切线问题、灯光高光，还是琴边饰几何露到爪前；不能凭看到亮线就断言真实断肢或穿模。root正在做射线／材质诊断，须用诊断确认原因、修复后再以两机位完整成片复评。旧r6一个连通分量与局部弦探针不能消除此项视觉P0。

### 其余握姿与准备形态

- **r3“无握持／无短趾结构”的两个P0未复发。** C4仍能辨认握琴短趾越过琴颈、指沟及内侧缺口；拨弦爪圆钝边缘和两条指沟也在。深色指板与橘毛没有粘成无法识别的一块。
- **原来的P1仍保留。** 拨弦掌背偏长扁，握琴爪指根团块与较长爪心仍像手套；新增的明显条纹没有自动改变这些体积。原图的短、厚、圆爪要更紧凑。
- **未发现仅凭两张图即可确认的大块爪穿琴面，但也没有精确接触证明。** 当前继续按准备姿态看待；爪到弦的有限静态间隙不是“正在拨弦”。r6探针只覆盖其7个命中爪区间、没有覆盖C4实际材质/groom/整个琴面或握琴区，不能跨版本泛化为C4全碰撞通过。
- **肩腕与足底动态仍未验证。** 两侧肩部与躯干看起来相连、足底落地；但当前没有新候选的蒙皮、极限弯腕、头／肩／呼吸动作、一次输入一次越弦或网页视频导出证据。这些仍不能从旧技术原型继承。

### 本轮结论与下一步

**C4在本接触／可动画性角色下暂不通过：先解除腕部亮弧这一静态P0，再扩大动作。** 这不是把不存在的动画判失败，而是成片已出现会破坏手部连续性的可见问题。

1. 先用root现有射线／材质诊断确定亮弧来源；别靠加毛、压暗或换有利机位遮住。修复后提交同机位完整正／侧图及腕部局部。
2. 复评确认前臂—腕—爪毛皮连续，并继续保留长扁掌背／握琴指根团块两个P1。
3. 只有全体C关P0解除后，再做准备／触弦／离弦三姿态和D0组合验证；本轮仍没有新动态通过结论。

### 本角色的静态放行范围

- C4亮弧P0解除，r3“无握持／无短趾”的旧P0仍未复发。C5握琴短趾越颈、内侧留空和拨弦圆钝边缘／指沟继续可见；双肩—前臂—爪视觉连接完整。
- **原P1没有因材质修复而被抹掉**：拨弦爪仍偏长扁，握琴指根团块／长爪心仍有手套感，相比原图厚短紧凑的猫爪还有距离。只解除本轮特定P0，不称已达到原图的全部完成度。
- 两张静帧未见可直接确认的大块爪穿琴面；这仍不是精确接触证明。当前按弦前准备姿态对待，r6有限探针不能扩成C5全接触／全碰撞通过。
- 极限弯腕、蒙皮体积、琴颈真实按弦、回程避弦、头眼／呼吸组合、输入时机和导出表现均未验证。静态看起来连续不能提前证明会自然动。

**本接触／可动画性角色对C5静态连续性给出窄范围放行：若身份和材质另外两名独立评审也没有剩余P0，可进入计划中的D0最小组合试验。** 这项允许只覆盖一条拨弦与一轮眨眼／视线组合的可行性验证，不是整套动画、正式页面或用户总目标的完成验收。

下一步仍控制为三项：①明确主要触弦边缘，提交准备／触弦／离弦三姿态并审实际间隙；②D0只测一条手动作在不同眨眼阶段进入，确认完整猫爪琴同帧、头眼时钟不被每键重置；③检查局部弯腕体积、手停后回位、无积压补演，再决定是否扩动作。P1与所有未验证项继续保留。
