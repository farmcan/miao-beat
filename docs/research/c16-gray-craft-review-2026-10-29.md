# C16r2 灰模独立工艺评审

2026-10-29；角色：非 builder 的工艺 / 体积 / 光影评审。只读，未改模型、材质、渲染或动画。

**结论：不放行。腕掌仍有 P0，不能进入该资产的彩色或动画扩展。** 这不是对建模算法是否执行成功的否定；实际灰模的前掌和后圆垫仍被读成两个体积，没有达到原图一只短圆爪自然长在弯臂末端的效果。

## P0：掌根后仍是一块独立圆垫

在整身 3Q 中，按弦掌下方有两个向下的凸轮廓：前面较窄的小掌，后面更宽的圆形体积；两者之间的暗线把下缘分成两层。inside 特写尤其清楚：三根趾连着竖向前掌，前掌右后方伸出约同掌大小的宽圆垫。即使不看来源色，灰模阴影和轮廓就已经形成“前掌贴后饼”的读法。

原图的按弦爪虽圆厚，但掌背、掌根和前臂共同形成一个短而完整的握姿外壳。C16 前掌下端仍有独立终止感，随后才接后方圆垫；这个转折不能解释成自然软褶、毛绒厚度或轻微姿势差异。**这是主形体失败，增加毛或提高渲染采样不会解除。**

来源色中，r2 紫色是 3D 场替换/混合贡献，不是 r1 的蓝色第三连接体。本评审没有把紫色误认成另叠的一根腕杆；但实现已换为场替换，也不改变图上的双层体积。掌根与臂轴不一致是合理待验证假设，窄带插值影响仍未排除，不能只凭这组图证明唯一成因。

## 改善与 P1

- 与实际 C15 3Q 相比，长直横杆和躯干向下的尖鳍已消失，原弯臂 / 躯干外形恢复得更自然。这是真实改善，但并未消除新的后圆垫。
- 三根短圆趾的轮廓是实际体积，优于仅用刻缝暗示指头；趾根之间仍显等节距的鼓包感，后续需要更自然的指根汇入和轻微体积差异。当前先解决 P0，不先加趾缝细节。
- 前掌偏长、掌面大区较平，下端像独立圆片的边缘。它与后圆垫共同强化装配感；单独把掌底倒圆或压薄不足以解决连接方向。
- 当前灰模还有旧拨弦爪的长袋掌 / 刻线、硬耳槽及原头形等已知差距。这些不是本次新退化，也未因 C16 局部比较而获得整身质量放行。头部另一路 C14 的窄通过不能自动套到本 native。

## 几何审计的边界

单连通、闭合、腕 patch 0 自交 / 翻面，说明没有本轮检查发现的破洞或相交反例；它们不能证明腕掌解剖设计正确。审计 patch 的 290 边界属于裁出检查区，不写成完整猫破洞。

928990 个 quad 是体素提面的密集网格，不是围绕指根和腕关节设计的变形环线。wrist audit 中高价点和不规则价分布很多；未做 rig 测试，因此本评审不宣称一定会如何折坏，也不把“全 quad”称为 animation-ready。替换拓扑后的旧 UV / 毛根 / 绑定不能继续沿用旧验证。

## 下一项最小结构试验

先不改毛、灯或整身。保留当前可用的上掌 / 三趾与原弯臂可识别轮廓，**把前臂末端、掌根和下掌作为同一个未封口的控制笼共同设计**：前臂流入掌背，掌底不先收成一个闭合圆片再接另一个闭合端面。需要明确掌根朝向与实际臂轴，并让两者共用一组有方向的连接环，而不是再增加遮缝体积。

最便宜的证伪图是相同整身 3Q 和相同 inside 灰图：下缘应只有一条可解释的腕掌外轮廓，侧面不再出现前薄掌贴后宽饼；腕厚到掌背是连续、可转动的体积，同时保持原图的短圆松弛握姿。若仍需靠视角或阴影藏后圆垫，候选继续失败。接触间隙另由实际琴颈 / 弦检查，不能用“看起来抓住”替代。
