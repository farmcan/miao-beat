# C14 头／口鼻／耳灰模：独立身份复核

评审 2026-10-29；产物 2026-10-28；非 builder。实际打开原图 `public/character/instrument-scenes-v1/guitar/idle.jpg`，C14 四张 `gray-front.png` / `gray-three-quarter.png` / `gray-head-three-quarter.png` / `gray-head-side.png`，再看 C12r2 头3/4与 C8r2 正面；读取 C14 README、receipt、geometry-audit。未修改资产或 commit。

**结论：C12 两个新增 P0 均解除；允许有条件进入仅头部的材质诊断。** 这里不是称头已精致，也不是整体 B 通过。进入前仍须汇总另两位独立 reviewer；旧爪／掌腕 P0 不受本结论影响，不能扩大动画或替换正式角色。

| 项目 | 实际判断 |
| --- | --- |
| C12 横梁／唇台 P0 | **解除。** 正面胡须根附近不再有横贯整片颊面的水平亮梁；头3/4的鼻下体积变小且连续接到脸颊／下巴。side 也不再像下唇另推出一个大台。不是仅靠换相机：整帧正／3/4都有对应改善。 |
| C12 鼻口竖线消失 P0 | **解除。** 正面、3/4和头近景均可见鼻下线从圆鼻接到笑弧，恢复温和猫口的结构；没有 C12 鼻与笑线悬空分离的读感。side 的线可读但本阶段不据单张侧图推断动态附着。 |
| 圆鼻与口鼻主形 | 圆鼻保留，近鼻下已有浅软垫，比 C8 薄楔／平脸更合理。原图的宽软奶油口鼻仍应在材质阶段另对照，不因灰模小起伏便声称已达到原图的毛绒层次。 |
| **P1：耳缘／耳腔** | 背面厚度确实缩减，side 不再像 C12 那么厚的直柱；但正面耳尖与内壁仍是硬三角槽，3/4 的耳根折边偏硬。厚度数字下降不等于柔软短耳完成。需要真实耳缘厚薄与内凹面曲率整理，不能用毛发遮住硬墙。 |
| **P1：头颊／颅侧的桶形感** | 正面圆方脸尚可识别，侧面和3/4的大颊面仍偏直、缺乏柔和变化，冠顶也较平。它仍影响精致度；但原图无侧背，不能把某个具体侧深／颅后轮廓当精确目标。本轮未出现类似 C12 横梁那样新的方向性 P0。 |

**材质诊断的条件：** 同相机给原图与新彩色整帧／脸耳局部对照；保本轮鼻口线连续与浅软口鼻，不因色块、毛根重绑、阴影或眼材质而重新出现台阶／断线。耳槽与桶形 P1 原样列出，不把这一轮标成完成。若彩色把口鼻做成贴片、鼻线掩埋或眼部神态退化，返回灰模／附着步骤。

receipt 与 geometry-audit 的完整 POLY 曲线中间采样、无深埋中心和零 miss，与实际鼻口线恢复一致；它们不是本 reviewer 重跑的结果，不外推每个相机、闭眼、表情运动或最终渲染可见性。头 ROI／鼻自交0也不证明所有跨对象相交或动态安全。

来源只有单图，side／背面是重建假设；此处使用它们排除明显结构错误，不要求不存在的精确原背面。未做彩色、毛根重绑、眨眼、head follow、动画、Godot、网页或导出验收；C14也未与 C11 新爪合并验证。
