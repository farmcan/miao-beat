已修正的掌面轴映射属于真实使用错误纠正，不能继续拿之前的 edge-on 手面错误证明源手不适合。本次修正后仍失败，能证明的是**这组整体琴位、腕目标与肩肘路径仍不成立**，不能由一组 frame 推广为所有源姿势都不成立。原 Thumb1 CMC 本次未用，更不能声称其工作空间被否证。

## .70 → .55 统一缩放：有条件推荐一次验证

.55 / .70 ≈ **.7857**，即线性尺寸缩小约 **21.43%**。这是整个源琴统一缩放，保留143组件之间的比例、六弦与细节，不是再次压薄琴身、缩手、拉臂或重建琴。源猫四指与成熟geometry也保持原样。

### 为什么值得先验证

当前大头角色的胸前可用区狭窄，而琴上角、面板深度和手腕目标同时挤入该区。较小琴可能让长角离开下颌、缩短右腕目标的前伸距离、减轻袖口与板面的遮挡，让它更像在身前拿着一把小电琴。这是成本低、可逆、能够直接证伪布局假设的一项变化；比继续逐指 Euler 调参更先触及已测P0。

但“统一缩小”**不自动意味着**每一个目标都更靠近肩膀。结果取决于缩放pivot、琴的位置和缩放后如何重新以实际琴背定位。只在当前root上改scale、沿用原世界腕目标，不能检验新比例的可行性；腕目标必须来自缩放后的真实琴面 / 琴颈，且应重新测实际可达性。

### 可爱与成熟乐器之间的取舍

就当前成熟toon猫而言，小尺寸六弦电琴在风格上可以成立；六个调音钮、六弦、长品板、拾音器与桥的组合让它仍是可辨识的小电琴，不会仅因长度缩小就变成四弦ukulele。用户允许适合的成熟模板及简单风格变化，.70也不是用户硬限制，因此比例试验本身不违背目标。

**不过尚不能签“自然可爱”通过。** 当前 .70 的琴相对大头已经是偏小的演奏道具；.55会进一步偏离原图中琴占据腹部大面积的视觉权重。原尺寸四指 / 掌会相对更大，更容易遮住琴桥 / 拾音区，琴颈也会在掌内更细。如果完整图变成“大手包住一件小玩具”，哪怕碰撞统计降到0，也不满足“精致成熟乐器”的产品目标。

因此本角色给的是**一次比例布局验证 GO**，不是 .55候选、完整静态接触或最终Miao的GO。琴的独立craft GO只适用于源琴工艺；整合FAIL不会自动抹掉源琴质量，缩小后的整帧可读性也仍需独立三评。

## 最便宜的下一步与明确否定标准

### 第一步：不卷指、不美化，做一次固定 .55 布局 / 可达性探针

保留成熟猫 / 琴base geometry、源四指、原生arm rig、脸和原材质。固定唯一 .55统一scale，不跑多比例扫描；记录源琴统一缩放的pivot / world matrix。先沿用当前已声明的颈仰20°、板面上抬8°与躯干姿态，按缩后实际琴背与腹部有限体重新定位，不能仅沿用旧腕的世界坐标。

用实际缩后琴面 / 颈的支撑目标和当前已核对的掌框架重新求双腕与肘hint；不改变手指形体、不拉长骨段，也不以旋转某个手指关节替代掌腕退出。先测下颌 / 上角、袖 / 琴与掌腕核心有限体，再决定是否值得输出完整图。

**硬否定条件：**

- 任何一侧仍触发当前核心门：掌腕core实体inside / triangle overlap未清、reach>.98、腕目标误差>.2mm、肘屈曲<20°、腕弯折>40°或实际臂段拉伸。
- head / collar / arms与完整琴组件仍有已确认穿入；不能只测薄Body板而漏上角、弦、品、拾音器和螺钉。
- 为让数值过门必须非均匀压琴、改掌宽、缩手、伸臂或重建头 / 身 / 手。

这些门槛沿用已存在脚本，不能为 .55而放松。建议解算目标优先落在约≤90% reach的有余量区域，但这是本角色的布局偏好，**不是现有硬门或已验证最优值**；真正硬门仍按上文执行。零hit也不是连续实体完备证明，必须和实际图像一起用。

该 probe若核心通过，再出**同姿态完整front / 3Q +双手必要近景**，查看短肘余量、掌面方向与完整乐器读感。三角色在卷指前先判基本摆位；不靠换frame或遮挡隐藏P0。

### 第二步：只有基本布局通过，才考虑一次源支持的静态握持

按源原生finger / Thumb1控制器的正确轴和左右映射形成放松四指握持 / 拨弦姿态；目标由真实琴颈 / 弦与指腹方向给出，不继续盲猜Euler。它仍是静态适配，必须重新做实际全手、木体 / 硬件、弦与可见指间隔验证，然后由三非builder角色审实际colored完整结果。

**视觉否定条件：**琴在完整图中主要被掌 / 袖遮没、只剩小板和细棍；无法读出成熟六弦电琴；手势仍像张掌穿过琴而非托住 / 轻触；需要靠脸部遮挡、特殊单机位或改源手geometry才能成立。出现这些情况，即使比例probe数值通过，也否决该整合。

### 何时换更适合的成熟模板

当前尚不建议仅凭 .70失败立即抛弃 Wing It Cat；一次固定 .55布局证伪比更换整套成熟角色成本低。**若 .55仍需最大伸臂、穿掌退出无余量，或小琴与大掌的视觉关系被独立判为玩具化，就冻结这个比例结果，不继续第三、第四轮局部重建。** 此时反馈应转化为模板筛选条件：肩到腕较长、胸前空间更大、手掌相对琴颈比例更适合、作者支持的自然弯肘 / 握持姿势；也可选择没有长上角的另一把成熟六弦琴，保持乐器精致度而不必改角色解剖。

若新结果暴露明确的rig switch / 源控制器轴映射 / 量测目标错误，可按用户允许的 bounded integration-error correction处理；需先列出证据与不变geometry边界，不能把继续盲试或大形重造包装成“纠正集成”。任何修正都不绕过独立静态gate。
