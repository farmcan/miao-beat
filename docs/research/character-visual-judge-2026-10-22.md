# 角色造型与可爱度独立评审

日期：2026-10-22。只评造型和可爱度，不涉及乐器音色、谱子、业务流程或大范围界面改版。本轮只写本文，未改素材或运行时代码。

实际查看三张原始截图：`artifacts/v2-production-overview.png`、`artifacts/production-guitar-plush.png`、`artifacts/production-drums-plush.png`；另只读核对当前 `public/character.js` 与 `public/character/rig.css` 的组件能力。以下是视觉判断与设计建议，不是用户调研结论或转化率证据。

## 结论

现猫有制作完成度，也已有大眼和大头；继续加毛发、放大眼睛或提高分辨率，不能直接解决“不够可爱”。当前组合更像一只端坐等待合影的精致商品玩偶：正面高度对称、眼睛玻璃感强、耳朵挺立、两条前臂同时架起。它还缺少让人想接近的明确性格与松弛姿态。

建议选择一个具体方向：**还没睡醒、但手上很认真的灰黑糯团小猫**。保留灰黑毛、琥珀眼、鼠尾草绿耳机的识别身份；通过圆脸、软耳、短爪和轻微不对称建立气质。不要同时追求酷 DJ、真实幼猫、精致收藏玩偶和憨憨表情包。

## 逐项观察

| 项目 | 三张图中可见的现状 | 对可爱感的影响与判断 |
|---|---|---|
| 脸型 | 脸部轮廓偏竖向蛋形，下颌逐渐收窄；口鼻体积小但嘴周暗、表情收得很紧。 | 眼睛大，却没有足够饱满的两颊承接。优先把下半脸变成软而宽的圆弧，少一点尖下巴；不必把整头无限加大。 |
| 眼睛 | 琥珀色虹膜占比显眼，高光亮、眼缘清楚；双眼直视正前方，左右几乎镜像。 | 已经足够大。强金色环与玻璃高光容易读成“睁眼拍照”，也接近通用大眼玩偶。更轻的上眼睑、稍软的眼缘和轻微视线/表情不对称，比再扩大瞳孔更有角色感。不能靠 CSS 缩放整头假称已换表情。 |
| 头身比 | 大头、短身已经成立；耳尖与耳机把轮廓向上拉高，底部是横向团块。 | 单纯再放大头容易挤住乐器。需要的是“脸更宽、耳更短、前臂更短”，而非机械增加头占比。 |
| 爪子/前臂 | 左右上臂向两侧鼓起，形成两个深色拱形；爪尖同一高度、细长趾沟较清楚。吉他截图里两爪像整齐扶在琴上。 | 有一点抱臂/架肘的端正感，像在等指令。圆短的连指手套式爪形、两爪稍不同高、肘部收进身体，会更笨拙亲近。演奏时本来是爪背朝上，不能为了卖萌给两只朝下的爪子强贴肉垫。 |
| 耳机/猫耳 | 耳朵挺、尖、外张，耳机架和两侧耳罩都清晰。 | 耳机颜色很适配，可保留；但它和耳朵共同加强了“精神抖擞的商品正面照”。短一点、圆一点的耳尖，耳罩轻轻压住头毛，更符合软团气质。 |
| 毛色/对比 | 暖浅背景上的深灰猫轮廓可读，金眼也醒目；脸、躯干和前臂内部都是深灰，接触处有些混成一团。 | 不是缺少饱和色。需要局部层次：脸颊/口鼻略提亮，躯干略压暗，爪背与身体有软的明度差。全图提高亮度会洗掉黑猫身份，也不会自动改善姿态。 |
| 舞台比例 | 吉他/鼓截图中角色可辨，但在整页里只是小区域；全屏 overview 里的猫更小，周围留白明显。 | 微小的嘴角、眼睑与爪形变化会在产品尺寸里消失。需要以实际展示尺寸设计轮廓，不能只在 atlas 大图上看“精致”。全屏里优先增加角色整体可见尺寸，不继续缩成舞台中央的小图标。 |

## 三个最高优先改动

### 1. 先补一颗有性格的圆脸，不重做整套角色

保留琥珀眼与灰黑毛；改成更宽的脸颊、更短的下巴、稍短圆的耳朵。眼睛尺寸先不增加，降低金色亮边的锐利感，给很轻的上眼睑和一点松弛口型；左右不要完全对称。目标是在小尺寸时一眼读出“软、困、很认真”，而不是只读到“高清猫”。

**需补图**：现头 tile 把眼睛、嘴、猫耳和耳机烘焙在同一张图片中。脸型、眼神、嘴型、耳尖形状不能通过独立组件变换可靠修改。只需替换 head 组件，保持正面相机、同光向、透明底与原锚点；先不要重生整个 atlas 引入身体/手的身份漂移。若需要眨眼，补一张真实闭眼/半闭眼 head 状态，而不是挤扁整头冒充眨眼。

### 2. 把“架肘双拳”变成贴着乐器的两只小短爪

收进两侧前臂，让爪子在身体前方有自然松弛的高低差；爪尖宽圆，减少长趾沟和类似指节的线条。保持落点确实接触琴键/琴弦/鼓面。吉他模式尤其需要一只扶琴、另一只轻拨的意图，而非两只爪镜像压在同一平面上。

**现素材可先调**：左右 paw 本来独立，可小幅内收、缩短纵向占用、调整各乐器模式的高度与旋转；保留现有分手重触发。先用实际产品尺寸检查是否更像自然放手。

**可能需补图**：如果只调位置仍明显像握拳/粗壮长前臂，再补左右各一张更圆短的前爪。只靠把现爪压扁，容易让毛发和爪尖一起失真。不要直接给现朝下爪背贴粉色肉垫。

### 3. 让这只软团在实际舞台里看得清，再用小幅不对称姿态增加亲近感

全屏时的猫应比 overview 当前状态更有存在感。先把现四组件与乐器作为整体做一致构图调整，别只把头放大到压住手。默认头部可有极轻的倾斜、左右爪自然不同高，保持身体重心稳；用户敲键时仍以独立手部响应为主。静止时也应有角色性格，不依赖持续摇晃才能“活着”。

**现素材可完成**：角色框取景、整体缩放、头的静态微倾、两爪相对摆位，以及现有低幅呼吸。保留减弱动态设置。无需为此重画毛发或生成视频。

**变换做不到**：眼睛跟随、嘴角变化和真正眨眼；当前 head-follow 是整个头层变换，眼睛没有独立层。不要把这个实现描述成眼球独立控制或新增表情已经完成。

## 最便宜的验证方式

先做一组并排小样：左为当前猫，右为“只换圆脸 + 原爪轻内收 + 实际取景放大”。两边使用同一背景、同一乐器、同一显示尺寸，既看大图，也看全屏/手机实际尺寸。评估三个具体问题：能否迅速说出它的性格；是否像在认真演奏而不是摆拍；是否更想摸摸/点一下它。无需先做整套动画或重生全部资产。

这是下一轮可验证方案，没有冒称用户已经喜欢、已经生成或已经上线。当前的毛绒材质与品牌色可以保留，可爱度改进优先投在脸部性格、短爪姿态与实际可见尺寸。
