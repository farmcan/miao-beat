# Miao Beat 可玩首版证据审计 · 2026-10-22

## 判断与范围

已有版本可以作为“自由乐器演奏 + 节拍器 + 本地片段记录”的可玩首版交付。它不是滑动判分音游，也不是多轨编曲器。现阶段最值得补齐的是跨设备实际验收、人的声音试听和作品保存预期，而不是换框架、加入账号或重新实现音频引擎。

本轮职责为只读审计当前仓库及正式 release，新增本文件；没有修改 runtime、构建器或复盘 exporter，也没有重跑父任务正在执行的整套产品测试。热点候选的来源调查由本轮研究整合负责，本文件只定义接入条件，不为尚未核实的名称或传播量背书。

审计日期为 2026-10-22，时间均区分 UTC 与上海时间（UTC+8）。源码基线 HEAD `8919409`，正式 release 为 `cfb1618a7b5e344404b0110964932c9dd42f0b35`，版本 `0.4.0-mobile`。HEAD 后于生产的记录属于文档更新；不能仅凭 HEAD 不同认定部署滞后。此次源码比较未将未提交工作区或构建目录当作不可变生产依据。

证据分四级：

- **本轮直接核对**：读到当前源码/不可变提交，或重新取得正式 HTTP 响应与字节。
- **既有验收记录**：仓库文档及负责发布 Agent 的真实浏览器证明；本轮没有冒充重新做过。
- **实现存在，环境待验**：代码路径和自动回归存在，实际设备尚未覆盖。
- **未实现/待研究**：明确范围缺口，不用设计图或上游能力替代。

## 首版验收清单与停止条件

最小动作：用户打开正式网页→打开声音→任选乐器输入→看到猫动作并取得真实音频输出→开关节拍器→记录几击→导出→刷新→导入该文件→回放→进入/退出页面演奏模式。

- 发布层：正式release提交与受检构建一致；公开文件SHA逐项匹配；只部署白名单，无个人入口回链。
- 操作层：上述核心动作由真实浏览器完成，无新增生产错误；导入失败不清空旧片段，手弹可停止示范/回放。
- 数据层：文件明确是按键事件；版本/引擎/音色/毫秒与编码有约束；不承诺保存长按、力度、踏板或节拍器全程变化。
- 设备层：分别写桌面真实浏览器、CSS窄视口、原生全屏真实手势、实体触屏与声音试听的实际覆盖；不能合并成一个“手机已测”。
- 研究层：事实、源材料、设计推断、许可缺口和未验证项分开。候选源缺失时保留unknown，不制造增长/留存指标。
