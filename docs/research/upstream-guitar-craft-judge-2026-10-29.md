# Classic Guitar 独立静态 craft gate

## 判定

**素材基础制作质量：PASS，可晋级猫 + 琴的一次静态装配。最终整体抱琴 / 演奏 / 生产美术：未验收。**

该 PASS 表示实际下载素材的轮廓、体积与乐器结构足够作为成熟现成道具使用，不表示未经修整的灰亮侧板、品牌字样、近景音孔贴图已经达到最终标准。下一步应直接复用这把琴，与现成猫验证一次静态尺度和接触；没有理由在此时自行重造琴体、琴桥或琴弦。

## 实际工艺判断

| 检查项 | 观察 | 结论 |
|---|---|---|
| 整体形制与体积 | 双弧琴身、腰部、完整侧厚、深色指板与槽式琴头成立；没有薄纸板、散件错接或粗糙 primitive 拼装的视觉问题 | 基础造型通过，适合现成道具路线 |
| 琴桥与六弦 | 本地近图能分辨六根弦从琴桥向上延伸，琴码 / 弦结有立体层次；弦跨过黑色音孔，非面板上画六条线 | 足够建立猫爪与琴桥 / 音孔附近的空间接触。未证明真实弦高、弦距或拨弦轨迹正确 |
| 琴颈与品丝 | 本地颈部近图显示连续六弦、横向品丝、琴枕和琴头卷弦结构；琴颈与琴身连接可读 | 静态握持没有明显几何阻挡。audit 记录 18 个独立品丝岛；不由数量推导可演奏性 |
| 表面细节 | 深浅木材分区清楚，琴桥木纹方向与面板不同，整体比粗糙替代品成熟；音孔圈放大后明显发软，面板木纹偏平，侧板近金属灰亮 | 可以用于全身装配验证；当前质感不能直接签最终近景成品 |

审计表明它是单个 joined mesh，55 个连通岛，无 rig / modifiers，scale 为 1；六根长弦为真实连通岛但尚非六个独立对象。静态接触不要求先拆弦或建 rig。若以后需要弦的独立响应，再在该阶段评估；本轮不因此扩展动画工作。

## 最多三个关键风险与处置

1. **局部外观修整，P1；不阻挡静态装配，阻挡原样宣布最终外观完成。** 侧板明显偏灰且高反射，与参考暖棕木侧不一致；音孔圈纹样放大后软化；琴头可辨认 Ibanez 字样，与项目原参考的无品牌琴不同。建议用局部材质 / 贴图编辑获得暖棕侧板、合适粗糙度、干净无品牌琴头，音孔圈在目标最终像素尺寸复核。它只有一个材质，并存在分通道纹理节点，因此不能假设“全局改一个颜色或粗糙度”就能只修侧板；需要先确认相应 UV / 纹理区域。此类问题目前更像有边界的表面修整，不是必须重建几何的理由。不能用单纯放大贴图分辨率声称恢复原本缺失的音孔细节。琴头标识须在最终版本中处理；本轮未完成处理。
2. **猫与琴的尺度和手接触，P0（整体抱琴 / 动画门）；当前未验证。** 原生琴外尺寸为 0.413772 × 0.139267 × 1.111706 m；现成 Wing It 猫检查包的整体高度约 1.164，同尺度直接摆放时琴长接近猫高。文件尺寸本身没有明显异常，但大头小躯干猫的自然抱持比例不能由此确认。允许对整把琴统一缩放、旋转和平移，在完整镜头内验证琴身落点、短臂承托、拇指绕琴颈、指腹贴弦、腕 / 袖口无明显穿插；不能为迁就琴而先拉长猫手臂，也不能只缩琴颈或放大手来掩盖失败。没有上述静态实图，不能说已抱琴成功。
3. **最终运行预算未验，P1；不阻挡离线静态装配。** 75,507 faces、三张 4K 图可用于本地静态检验，但文件大小不是浏览器交付大小，也没有渲染耗时 / 最终帧资源预算证据。若最终交付全帧渲染，只需测相应渲染与图像资源；若未来改为实时浏览器模型，须另测并优化，不能沿用本次 PASS 推导实时性能。

## Gate 的具体边界

- **现在允许：** 以原有完整成熟几何为基础进入一次猫 + 琴静态装配；并行准备局部无品牌、暖木侧板与音孔圈的外观修整。允许尝试装配不等于这把琴已经是最终成品。
- **下一道门：** 同一完整画面内展示连接的猫、双臂 / 双爪与琴；同时提供脸部、握颈爪、拨弦爪和琴身接触区裁切，先验尺度与接触，再验目标光照下的材质。身份 / craft / motion 独立 reviewer 复核通过后才能扩动作。
- **仍未验证：** 按弦与拨弦动作、物理可演奏性、弦振动、关节极限、浏览器交互和音画响应。没有用本地构图、已有六弦或 CC0 标签替代这些验证。

本报告是本地内部评审证据；公共状态由主任务统一接入既有 Seed 状态机制，不能提前记作抱琴或演奏功能完成。
