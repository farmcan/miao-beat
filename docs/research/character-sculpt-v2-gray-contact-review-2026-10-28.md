# 连续曲面 v2 r3 灰模：抱琴、关节与可动画性独立评审

2026-10-28。评审角色：抱琴接触／关节结构／后续演奏与网页体验。评审者未参与该灰模的建模或渲染；另负责的 Modelr 试验不是本次评审对象。

## 实际查看的证据

- 主参考：`public/character/instrument-scenes-v1/guitar/idle.jpg`。
- 候选：`artifacts/character-sculpt-v2-r3/gray-front.png`、`gray-three-quarter.png`。
- 实现：`design/character-sculpt-v2/scene.py`（读取时为 r3，双臂 sweep 并入主体后 voxel remesh `.015`，无骨架／权重／手指结构）。

本关只评价灰模静态可见结构及实现风险。新动画、声音对应、单按／连续按、网页、录制导出均**尚未验证**；不因旧原型通过这些功能就算本候选通过。

## 结论：相较旧原型有结构进步，抱琴与爪形仍未通过 B 关

宽胖躯干和从肩部连续伸出的双臂，比球肩、管臂、分离爪的旧样机更适合继续雕刻。琴的斜度和尺度也接近主参考的大琴构图。但当前双爪主要是无指沟的椭圆／水滴体积，原图清楚的“包住琴颈”和“弯爪触弦”信息丢失。不能直接以此做一条腕骨开始扩动画；需要先在静态近景中证明抱持与触弦结构。

| 优先级 | 实际可见／可核实的缺口 | 对后续工作的影响 |
| --- | --- | --- |
| P0 | 画面右侧握琴爪呈竖立的圆椭球，盖在指板前面，未形成原图中可辨认的弯曲指沟、卷握边缘和绕琴颈的包覆。三分之四视图同样像贴住琴颈的单块软垫。 | 当前只证明爪与琴颈投影相遇，无法证明是自然握住；直接移动容易变成整块爪贴着指板滑行。需先雕出握持形态，并检查背侧承托／内侧空间。 |
| P0 | 画面左侧拨弦爪向琴孔附近收成较尖的水滴轮廓，没有原图厚而圆的爪背、折起的短指和指沟。正面看爪尖在琴孔左上方附近；当前没有一个可辨认的触弦指／爪缘。 | 即使后续数值接触正确，用户仍难看出“是哪个部位拨过弦”。需定义一个圆钝的主要触弦边缘与放松腕部，避免尖端戳弦。 |
| P1 | 当前代码将肩、臂、爪与躯干 voxel 融合成一个表面；没有显式肩肘腕边流、蒙皮或局部弯折试验。渲染中的融合比旧原型自然，但握琴臂弯折处仍有鼓起的大块体积。 | 连续表面不等于可变形拓扑，不能提前宣称可绑定。静态修形后须检查腕肘内侧间隙；以极窄范围局部变形试验证伪，不先扩整段动画。 |
| P1 | 弦与爪的实际距离未有本候选的几何审计；静帧无法排除轻微浮空或弦从爪中穿过。 | 本评审不把“看起来靠近”写成准确触弦，也不凭阴影断言已穿模。下一步须给完整场景的近景和弦面／爪表面最近距离，允许软组织极小压入但不能明显穿琴面。 |

## 下一步最多三项

1. **先改双爪，不加动画**：还原原图握琴爪的卷握与指沟、拨弦爪的厚圆爪背和弯指，保留短肢并让肩腕连续。补正面／同机位局部，以及能看见握琴内侧和腕部的诊断角度。
2. **确认接触与可弯折空间**：分清琴颈／弦面／琴面和爪的对象边界；给爪与六弦的距离或接触点证据。明确哪些体积目前为静态雕刻、哪些准备重拓扑，不能把 remesh 当现成 rig。
3. **重审 B 关后才进入材质及动作**：本轮 P0 未解决，暂不扩毛发、眨眼或拨弦序列。将来第一次局部形变试验只测准备／触弦／离弦三姿态，仍保留每帧完整猫、相连爪和琴。

本结论不评价未制作的毛绒材质，不以无毛灰模本身作为失败理由，也不把任何图像差值当作自然度总分。

## r6 追加复评：双爪已有可辨形态，接触精度仍须审计

实际另开了 `artifacts/character-sculpt-v2-r6/gray-front.png` 和 `gray-three-quarter.png`，并核对当前 scene.py 的短趾、琴颈留空 Boolean、相机标线真实指沟与前爪向前移位实现。以下判断来自图像；代码只用于确认不是贴上两条装饰线，不能替代自然度判断。

- **r3 拨弦爪 P0 → r6 结构性缺口解除，仍有 P1 修形项。** r6 爪尖变为圆钝边缘，两条指沟在正面和侧面都可见，已经能读成弯曲短趾而非无指的水滴。肩—前臂—爪保持连续，没有旧样机的独立圆肩。仍比原图更长、更扁，腕背到指根的体积过渡偏平滑；应在 C 静帧继续检查，不把加沟本身当精致完成。
- **r3 握琴爪 P0 → r6 基本卷握信息已建立，残留 P1。** 琴颈上方可见短趾越过琴颈，指沟帮助读出卷握，侧面也能看到爪内侧留出的空间；不再只是 r3 的完整椭圆贴片。但指根上方的几个团状起伏偏突出，爪心仍像较长的手套；原图是更短厚、更紧凑的猫爪。这是下一轮需克制修小的形体差距，避免加成人手的大拇指。
- **静态接触距离目前仍为未验证。** 两张图未见明显穿过琴面的大块体积；拨弦爪确实移到了弦前方，但正面投影相遇无法证明触弦。需读取本候选 ray/最近表面区间审计，再标明目前是准备姿态还是接触姿态。尚未有审计时不写“准确接触”。
- **可动画性仍有 P1 技术风险。** 连续 mesh 对外观有益，现阶段无肩肘腕变形边流或蒙皮证明；这不要求 B 关已经有成片动画，但限制后续直接套 rig 的承诺。现有 Boolean 内侧留空在弯腕后是否闭合／拉裂需 D 阶段小姿态验证。

**本评审职责范围内，r6 不再保留 r3 那两个“完全缺少握持／触弦爪结构”的 P0。** 可以在另外两名静态评审也解除其 P0 后推进 C 关；这不是最终美术、动作或发布通过。爪形紧凑度、指根团块与接触审计仍列为 P1／未验证，不因本结论被静默丢弃。如果几何审计证实爪或弦明显穿琴、或握持内侧没有实际空间，应将具体接触项升级为 P0 并修复。

下一步缩为三项：读取实际接触审计；在 C 同机位爪近景收紧手套感与短趾团块；C 通过后才做三姿态局部形变。全套动画／网页／音频同步／导出仍未验证。

### r6 几何审计补证

随后实际读取 `artifacts/character-sculpt-v2-r6/geometry-audit.json`：evaluated 猫网格610764顶点／610762面，连通分量为一个（610764顶点）；30个指定弦位置探针中7个命中被分类为爪的表面区间，0个探针的弦深度落入该爪区间。该7个位置弦到爪区间后边界的深度差约0.05774～0.15121场景单位，表明这组采样是**爪在弦前的准备姿态**，不能称接触姿态。

证据只支持这些有限静态采样未见弦穿过所分类的爪区间。23个未命中爪区间的点不能当成23次接触通过；分类靠深度启发式排除琴后躯干，且没有覆盖整只爪、整张琴面、握琴爪、关节变形或全程动画。一个连通分量也只证明几何连接，不证明自然握持或可变形拓扑。保留原结论：B阶段可继续雕刻／C评审；D阶段仍须真实触弦、离弦和极限姿态验证。
