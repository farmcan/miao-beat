## C44：可以解除什么

解析脚本对保存重开的完整 actual mesh 计算三角形有向 solid angle 总和 / 4π；输入转 float64，以三角中心和单位实际法线的正负偏移求值，没有重复 BVH 射线步进。四面体已知内外点先校验符号与归一化；源码没有保存 native 的动作。方法与本次要回答的“这些近表面点分别在内还是外”相符，不再依赖原来两条可能产生方向分歧的 parity ray。

本角色另以普通 Python 做了**独立 JSON 一致性检查**，没有重跑 Blender 或 solid-angle 数值积分：

- C40 原始 `actual-normal-side-parity.json` 中未通过的唯一三角顶点 tuple 共 20 个，与 C44 标注 `previously_ambiguous=true` 的 20 个 tuple **集合完全相同**，无漏项或重复替代。
- 每项均有 `2e-6 / 1e-5 / 2e-5u` 三档正负侧偏移，共 **60 对**。原射线检查所用 `2e-5u` 也在其中，而非仅换到较远位置绕开原问题。
- 所有这些数值均满足外侧 winding 约 0、内侧约 1，以及声明的 `1e-6` 误差门槛；7 个原本一致的控制项也符合该条件。
- 本角色重新计算磁盘上 C40 native 文件 SHA256，仍是 `6dbc4183a57117079c1479b0c1361e52995f66ff3eaef3f2d3e00e1cba8bdc00`，与 C44 输入及原 C40 冻结身份一致。C44 receipt SHA256 为 `da727f90b2244da98e8552d2dc2b13abbfd25728d25d0ae8873685586a66846a`。

因此，原来“20 处方向分歧仍未知”的结论可以由本补证更新为：**这 20 个指定三角中心的三档正负侧采样，已有支持 outward-correct 的直接 winding 证据，原法线侧采样未知解除。** 不继续把旧射线分歧当作这些位置的确定失败，也不把它们写成曾经已证实 inside-out。

## C44：没有解除什么

旧 C40 失败回执保留是正确的；新补证是追加的裁定证据，不是新形体，不应覆盖历史记录。可以明确说“原 20 项 normal-side 采样阻塞已解除”，但不能仅据此把旧 `geometry_gate_passed=false` 静默改写成整体通过。

C44 对完整 mesh 求和，是为了给**有限 query 点**分类；它不等于检查完整表面每一点或所有姿态。它没有重算原 606 项中的全部项目（另取了 7 个控制），没有证明全身连续体积无自交、所有面向外、全琴碰撞为零，也没有检验 UV、毛绑定、关节变形、外观或动态。既有 C40 local self18→0、闭合和局部琴交对证据仍各自限于原审计范围。

本角色原先的 C38 / C40 / C34 文档中，对这 20 项保留未知反映当时证据；现在应与本追加记录一起阅读。**20 项解除不改变整体猫仍需静态三评的结论，也不产生 art / motion pass。**

## C41：完整右臂实际形体仍失败

这里的右臂指猫自身右侧、正面图画面左侧。当前两张图都同时包含完整猫、双臂 / 双爪与吉他；没有拿局部胳膊截图冒充生产整帧。共享皮肤 / 真实前后面与负空间是结构方法上的进展，但视觉判断必须回到原图。

**P0-1：末端仍是平切袖口加三根 stub，没有完整短圆掌。** 正面可见前臂到末端突然形成斜直收口，三个浅色短柱从收口外伸；三分之四中掌端更像一个截断截面，趾根与掌体的共同体积没有被读出。原图则是厚而短的掌体逐渐收圆，浅分缝解释短圆趾，不出现“袖筒伸出几根杆”的形状。

这不只是可爱程度差异。动作需要一个可追踪的短掌缘、趾端及合理掌根，观众才能读出小幅触弦；当前分件式读感会把动作解释为整个袖筒摆动，或者三根小杆单独戳弦。数值闭合、共享 web 边和全身单连通都不能消除此可见动作结构 P0。

**P0-2：上臂 / 前臂偏细直，肘部断折像焊缝。** 三分之四中肩到肘是一根较窄的弯管，肘上方能看到短而清晰的接线，接线两侧体积与方向变化突然。正面也能看到这一处划断。原图肘、前臂、圆掌通过连续丰满体积和琴身遮挡组成软弧；当前细管和宽阔腋下空隙把手臂从躯干上分离出来，短肢身份仍不成立。

真实共享 mesh 证明它不是独立浮肢，但不证明变形时体积合理。若在当前肘接线处做弯曲，很可能强化机械折点；这是静态形体暴露的风险，**没有实际动态帧，不能写成已观察到动中断裂或翻面**。

**P0-3：右爪与琴的静态意图仍不足以支持演奏。** 当前趾柱大致指向音孔 / 弦区，能表示手在琴前；但没有恢复原图厚掌自然覆在音孔左侧弦区的松弛姿态。尤其三分之四中，看不清短掌缘由何处开始、哪个点先靠近弦、回位需要哪段余量。不能仅因最近一个 sampled gap 落入 idle 目标，就认证拨弦起势、触弦或连续接触路径。

## C41：把已知几何失败归到正确位置

完整草模回执记录 component1、boundary0、nonmanifold0、Euler2，保留 499690 个原点及新增 4593 点；readback 支持头、x>0、C35 左手 5359 点、来源属性及吉他几何 / 变换精确保留。**这些支持共享拼接与身份保留可行，不支持当前外形或动态合格。**

本角色独立从归因文件完整 `actual_self_pairs` 列表重新统计，得到 **172 对 = arm-arm156 + arm-toe16**，与摘要一致；不是把躯干补面 / 肩根误当这批 self 的发生部位。具体三角自交未由本角色重算。

木体证据也必须拆开：

- **rosewood18 对全部归到 region1 躯干补面**；wood parity 另有 11 个 inside 与 1 个 ambiguous，仍是完整候选阻塞，不能用局部 surface0 覆盖。
- 新 arm / toe 对木件和六根实际 tube 的表面相交记录是 0；不据完整候选的 rosewood18 对声称“右趾已证实穿木”。
- 六弦 sampled toe-vertex-to-actual-tube gap 为约 `.138699 / .103393 / .072058 / .046397 / .033793 / .037184u`。最近第5弦 `.033793u` 在声明 idle `.02–.04u` 内；这是有限顶点采样，不是六弦均近接触、全连续表面最短距离、真实触弦或动态扫掠无碰撞证明。

故当前应保留两种不同事实：**完整模型有已报告的 self 与躯干补面穿木阻塞；右臂 / 趾的木体交对0和一个 idle 近距样本有局部证据。** 二者都不能替代当前短掌、肘与形体的视觉失败。

## 动态状态与后续验收

本轮没有 rig、权重 / shape 变形、肘弯曲帧、腕部旋转、趾端触弦、拨弦 / 扫弦轨迹、回位、连续手琴接触、乐句级头眼响应、眨眼、呼吸或实际按键音画 / 网页体验证据。这些都为**未制作 / 未验证**；不从数值推断可爱、自然或可演奏，也不把静态风险伪装成已经发生的动态失败。

C41 可以保留共享边界、补面与 exact 来源映射的方法结论；**拒绝把细管、肘焊缝、平袖口和 stub 形体带入整合。** 下一形体应先用原图确定肩—肘—掌根—趾端的投影轮廓与宽厚，在完整正面 / 三分之四中恢复连续丰满短肢和圆掌，再核查实际几何与静态琴关系。只有整体灰模及 shaded still 独立三评通过后，才制作最小动态证伪；每个生产帧继续保留完整连接的猫、双爪和琴。
