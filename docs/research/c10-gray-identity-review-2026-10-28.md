# C10r3 按弦爪灰模：独立身份／体积评审

2026-10-28；非 builder。实际打开原图 `public/character/instrument-scenes-v1/guitar/idle.jpg`，C10r3 `gray-front.png`、`gray-three-quarter.png`、`gray-grip-inside.png`，并与 C8／C9 已实看的正侧灰模、C8 彩色和本轮再开的 C9 侧图对照；读取 `receipt.json`、`hand-audit.json`。未改资产、未 commit。

**结论：有真正的掌趾结构进展，但按弦爪的身份／体积窄关仍未通过。** 不再将它归为 C9 的“横盖凸块 + 刻沟”。新三趾有独立圆头、趾根和弯曲方向，掌趾读感比旧版清楚，应保留这条重建路线。然而掌体的扁长叶片形、尖底和宽腕底座仍偏离原图的饱满短圆爪；不扩彩色和动作。此结论也绝不代表整体 B 通过。

## 从实际图看到的变化

- **改善成立：** 正面琴颈上可分辨三根短圆趾；侧面和 inside 近景可见它们从掌体升起再弯向琴颈的曲率，不只是刻线。旧版横向凸条和几道细夹缝的主要外观已解除。
- **保留了角色线索：** 爪仍处在原来按弦位置，趾端没有长成写实人手的长细指或另换成爪甲风格。整体抱琴关系没有因本次手重建而明显换动作。
- 毛发因拓扑绑定失效而隐藏属于已声明的阶段限制；本轮不以无毛判造型失败，也不拿隐藏毛发后的平滑表面当已完成工艺。

## 技术证据的作用边界

hand-audit 报告的是独立重建手的 **2650 顶点、2648 四边面、零边界／非流形／自交**；这些有助于排除一部分网格错误，不证明“可爱”“自然抱琴”或关节变形合格。receipt 表明手已并入完整连续身体，但腕部仍需变形重拓扑／权重，旧 groom / UV / shape-key 证据不再自动适用。

receipt 也明确旧 `contacts` 表因射线方向与琴颈斜率计算问题失效，并指向替代 `contact-audit.json`。本评审不以旧表的命中／距离证明接触；精确触弦、穿插、蒙皮、curl 极限与生产整帧动作仍交独立 contact/motion 角色，均未计通过。
