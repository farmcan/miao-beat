# 第二版：选一首，跟着亮起的键弹

更新：2026-10-22。当前发布候选为 `0.5.0-v2`。核心仍是自由演奏；参考提示可以随时开始/停止，不做判分、下落轨道或强制通关。

## 这版具体改变

- **选谱移进演奏区**：普通页面、手机与全屏演奏都能选。钢琴/马林巴/吉他显示7项旋律，鼓组显示2条原创节奏；按入门、黑键、半拍分组。总计9项，并非9首完整歌曲。
- **“听一遍”与“跟着弹”分开**：听一遍会播放旋律，手弹即可接手；跟着弹只放节拍与提示，旋律由用户弹。没有敲击就不增加演奏次数，也不写进录制。
- **一条可读的时间线**：音符向左移动，到固定竖线时按相应字母键；当前键用蓝绿色边框，真正按下用原来的按键反馈。显示当前音名、下一键和经过秒数；音条长度表示到下一次触发的时间，不意味着采样会持续那么久。
- **速度与取消规则清楚**：使用当前BPM，按曲谱拍号开始。改速度/拍号会停止旧提示，明确提示重新开始；选谱、换乐器、失焦和页面切后台清掉旧提示。导入演奏文件仍按原始毫秒回放，不被练习BPM拉伸。
- **音乐拍点对齐**：普通谱先预备一小节；《生日快乐》保留一拍弱起，先两拍预备，首个C落第三拍，随后D为强拍。中途开关节拍也沿用同一时间起点。
- **猫爪动作修补**：快速同爪重按从当前姿态衔接；结束交回实时CSS按住状态，避免松手后回到旧姿态。运行中启用减少动态会取消已在播的爪动作和视线跟随。原PNG与四组件结构继续复用。

## 怎样试玩

1. 选乐器与一首谱；先“听一遍”。钢琴等首次需要准备真实采样。
2. 把速度降到自己舒服的范围，点“跟着弹”，听预备拍，音符到竖线时按字母键或大琴键。
3. 可以提前、延后或改音；提示不会判错，也不会阻止创作。跟弹中可以开始记录，文件只留自己的敲击。
4. 点停止回到自由演奏。想留住片段时主动导出；记录还没有自动恢复或云存档。

“时钟准确”与“设备零延迟”是两件事。音符位置按 AudioContext.currentTime 计算，rAF只画图；窗口卡顿后直接跳到当前位置，不累计帧数。音频仍采用短前看排程，真实扬声器、无线耳机和触屏存在各自延迟；本轮不声称量过这些延迟。

## 可选内容与边界

| 组 | 内容 | 说明 |
| --- | --- | --- |
| 入门旋律 | 小星星、玛丽小羊、月光下（法国童谣） | 底层古谱旋律的独立单线适配，不采用现代伴奏/歌词/录音 |
| 进阶一点 | 生日快乐、欢乐颂主题、两只老虎单八度版 | 分别练黑键、半拍；两虎末句低G明确升八度以适配现有键盘 |
| 短参考 | 粉刷匠开头 | 仍仅七音，完整版本来源许可未补齐，不称全曲 |
| 鼓组 | 底鼓/军鼓四拍、加踩镲八拍 | 原创基础练习；加号代表同一时间两键 |

每个新增旋律的古谱、转调、整拍简化与休止合并见谱子来源章。所有数字仍是固定C键位数字，不冒充每首调性的首调唱名；时间线当前音另外显示真实音名。

## 参考优秀作品后的取舍

- **Bongo Cat**：学每次输入与左右爪的清楚联系；保留来源许可，不复用其角色或录音。
- **Patatap**：学动作短、可被下一次输入打断、提示适时退场；不照搬整屏禁止滚动，因为本站手机需要滑琴键。
- **Chrome Music Lab Melody Maker**：学独立清楚的音乐位置和停止清理；该仓库已归档，旧Tone/AMD栈不适合直接搬进当前小站。
- **Ableton Learning Music**：官方练习先给可操作的音符/节拍，再鼓励自己组合；这是交互分层参考，不复制其声音、教学内容或界面资产。

详细源码和许可证核对见动画与引导研究章。[Ableton 原始练习页面](https://learningmusic.ableton.com/notes-and-scales/play-with-notes-and-scales.html)确认能探索音阶并与节拍同步；本轮没有实际通玩或取得其复用许可。没有用Stars、作者自述或网站存在，代替本项目留存/音质的验证。

动画路线仍推荐 **原创2.5D组件 + SVG道具 + 可打断短动作**。真3D需要关节、网格、素材和手机性能验收；GIF无法自然组合左右手与快速输入。若以后要精确拨弦或吹瓶嘴型，先补少量真实局部状态，不先生成几十段整猫视频。

## 本地与浏览器验收

- 37项自动回归通过：包含计时位置/半拍/卡顿、共享起点、弱起、鼓双键、提示不污染录制、示范手弹接手、停止后重新开、加载取消、旧文件和全屏回归。替身音频测试与真实库参数检查不证明人类听感。
- 实际Chrome：跟弹中手弹两音，提示继续、hits仅2、输出电平非零peak .02089；停止后清高光。三次钢琴输入后两爪释放姿态均回到CSS的none，毛绒组件就绪、输出非零。角色插值的主观自然度未做盲评。
- 390×844 / 844×390为真实Chromium CSS视口iframe检查，**不是手机硬件实测**。白键约73.71px、黑键44.29px；横屏跟弹时8鼓垫约198×64px，最下缘386.07px，处于390px高视口内。横屏提示展开时暂收舞台，保留退出和可滚动控件。
- 减少动态偏好下，时间线改为按当前音离散定位，不连续滑动；角色偏好变化已做离线行为检查。真实设备的系统设置切换、多人触屏和端到端延迟仍待验。
