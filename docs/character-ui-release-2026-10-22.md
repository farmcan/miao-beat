# 猫的触点与首屏迭代 · 0.6.0

2026-10-22，北京时间。用户授权优化角色/UI、启动独立subagents评审、查询社区参考，并明确要求先上线一版，至少手部动作对上。

## 采用的判断

三位独立评审分别检查角色、UI与内容价值。共识是首声、看得见的回应、已有片段的回听优先；暂不扩音库、分享后台或3D。角色评审在用户指出丑、不够可爱与酷后，撤回墨爪可直接进入动画的建议：长腿细身与巨大白手套只证明差异，没有通过审美。

社区实际作品与许可见 `research/community-character-references-2026-10-22.md`。借鉴团块、注意力、静止与爆发的组织，不复制角色、音乐或素材。新角色用内置imagegen生成，完整prompt在 `design/indie-cat-v2-prompt.txt`；原PNG复制到项目，未编辑像素。折耳尖、短宽脸、墨蓝毛色和天然奶白足尖比长身白手套更像猫；生成结果仍有毛发与通用吉祥物感，酷感偏弱，是可玩迭代，未称最终品牌或人类审美验证通过。

## 实际改动

- 头、躯干/尾、左右前臂爪四部分独立控制；原图谱仍保留。继续SVG合成与WAAPI，不引入3D或新动画框架。
- 肩点固定，爪尖按每个琴键映射；13音有13个落点。接触是动画第一帧，随后短回弹，不等预备动作才发声。
- 吉他所有旋律与和弦都在音孔拨/扫，另一爪在琴颈保持简化按弦姿态，不声称逐指真实把位。
- 鼓组补军鼓、crash与脚踏槌；开/闭镲使用同一hi-hat，开镲分层上抬，底鼓用槌而非手拍。鼓棒尖落面，爪与棒同步回程；快速同侧重击只取消该侧，失焦/切模式复位。旋律模式的鼓点在可见电子鼓垫上响应。
- 评审发现短按及示范回放中，鼓棒底层终点可能残留接触位置、与爪回程分离。已改为两者始终共用实时held/rest终点，接触仅由动画首帧提供，并加入回归检查。
- 标题“随手一弹，猫就来劲。”；声音入口前置，默认先自由琴键、后口袋谱；压缩舞台和节拍区。演奏文件保存文案隐藏JSON技术词；录音格式与音库不变。

## 本地证据

- 41项自动测试：原回归39项，加接触几何/肩爪映射、独立重击、中途释放、示范鼓棒终点、切模式、失焦/destroy等行为。它们含DOM与音频替身，不是人类听感或原生插值证明。
- 实际Chrome本地：13个旋律键与6次快速重击，hits=19，peak=.05818；8鼓后hits=27，peak=.06245；4和弦、两音与混合底鼓后hits=34，peak=.09639，最后surface=pad-kick。
- 实际持键截图检查钢琴C、吉他C和闭镲：爪缘/棒尖位于对应键面、音孔/镲面；释放后无active按键。未声称逐帧测量声画延迟。
- 390×844真实浏览器视口（非手机硬件）：scrollY=0，scene底298.65、琴键底699.24，页面宽390无整页横向溢出；琴键内部保留横向滑动。
- 横屏自由演奏实际检查发现未开启的口袋谱工具栏挤占空间，导致第二排鼓垫超出390高视口；已调整为自由演奏先鼓垫、跟弹时再前置时间线，修后重新验收。
- 跟弹同时记录三个真实音，文件146字节，290ms，仅事件 `[238,0] [250,2] [255,4]`；引导继续运行且没有把节拍/提示写入文件。

## 边界

没有实体手机、多指物理触屏、扬声器主观听审、延迟仪测或真实用户审美/分享实验。远近目标会使整段前臂/爪缩放，个别姿态爪大小仍不一致；后续可改为固定爪尺寸和两段关节，但本版不冒称解剖准确。短横屏跟弹仍沿用原先收起舞台以保住琴键的布局，完整角色反馈优先在自由演奏/常规页面检查。

开始事件已追加既有Seed任务源，并持久化待发布副本。状态站正在使用全路由密码保护；不得从旧工作树整站重发而回退鉴权。生产结果、状态事件是否已发布在验收后追加，不能用本地文件代替线上成功。
