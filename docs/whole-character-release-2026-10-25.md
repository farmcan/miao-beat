# 完整钢琴猫 · 0.8.0 · 2026-10-25

用户提供另一条新键盘视频后，本轮先归档，随后接入完整姿态。原始MP4保存在本地Git忽略目录；可跨电脑取用的去元数据无声预览、图集、映射、导出脚本与交互实现均提交。旧过期素材没有找回，历史缺失记录保留。

## 素材与实现

- 原片：2,775,311字节，10.041667秒，1280×720、24fps、无音轨。SHA-256 `17a223bc41021898f120d2660b4c0787660a07ff157d1910d8f2f6f2572bd8a5`。
- 全片预览：`/labs/keyboard-motion/`；视频为视频流无重编码、去元数据、faststart重封装，SHA与原容器不同。未保存或发布签名参数。
- 统一裁切/缩放13个完整姿态，不拆手、头与琴。四音区+双手接触，按下立即选接触，最短110ms，松开每70ms走回弹帧，停在对应分支的完整末姿。连续输入直接接新状态，不排队重启十秒表演。
- 默认钢琴；其他三种乐器保留原rig，只在切换需要时加载旧角色图。资源失败回退原角色。声音仍走原真实输入路径，节拍/引导不被写成用户按键。
- 不是13个准确物理键，也不提供独立肢体控制：完整姿态包含身体和另一只爪的耦合变化。钢琴模式的额外打击乐垫保留发声，但不会让这段钢琴素材假装击鼓。自然度仍需用户审看。
- 新低/高音导航与短横屏全屏工具布局；保留手机pan-x，不将导航改善误记成修复了原本不存在的禁止横滚。

## 已做验证

- 本地45项自动测试通过：含快速打断、持续输入、左右/双手、松开、重置、打击乐不冒充钢琴姿态，以及已有录制、音频、引导与交互回归。
