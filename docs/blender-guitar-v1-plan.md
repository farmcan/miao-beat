## 线上如何运行

Blender离线建模、设定动作和打光，将每帧完整的猫、相连双爪、吉他渲染为图集。网页Canvas只绘制完整帧；音频沿用本站吉他采样，按键直接发声；动作由当前姿势继续，避免每次归零。访问者无需安装Blender，无服务端实时渲染。保留源脚本与blend以便重渲染，成品只发布必要图集。

首版独立入口 `/labs/blender-guitar/`，与正式版并存；不替换首页。实时WebGL后续有更灵活的连续控制，但需要合格模型/绑定和额外运行时，且现有用户约束要求生产画面完整，首版不引入这条支线。整段视频随机跳时刻难准确对应按键，本轮不采用。

## 分步验收

1. 环境：安装官方Apple Silicon Blender并实测后台渲染，不以下载完成代替可用。
2. 静帧：先检查脸部比例、爪臂连接、木质琴体/琴弦/品柱、软阴影与完整构图；明显穿模或拼装感先修再渲染序列。
3. 动作：24帧/60fps约0.4秒，一个周期只穿弦一次；0准备、2触弦、23回到相同准备。左爪固定扶颈，右爪短弧下拨并抬回，肩肘轻微配合。帧0与末帧位姿一致；GPU渲染仅允许极少像素1/255量化误差，打包记录真实误差，不假称逐字节确定。
4. 网页：单按只一下、按住不自动重复；连按不排队、不直接跳0，极快事件允许合并画面但声音按输入触发。慢放和压力测试方便观察。所有动作只画完整场景，不拆肢体。
5. 导出：复用已有音频图和Canvas媒体捕获，生成可下载视频；避免演示自动输入写进个人录制。
6. 发布：真实浏览器操作、文件轨道验证、静态产物校验、commit/push、独立测试页上线及状态留痕；自然度由实际查看与用户试用判断，实体手机听感另列待验。

## 并行分工

主agent：环境、产物检查/集成、构建、发布和状态留痕。场景agent：建模材质灯光与完整渲染。测试页agent：按键/图集状态机与本地媒体导出。评审agent：官方与GitHub参考、动作/界面/体验验收。

## 2026-10-28 执行进度

用户已自行安装Blender，实际CLI核对5.2.3 LTS/e13b728c6880；后台Cycles Metal渲染已成功。首轮未更新父级矩阵造成爪过大，已否决并修复；后续修正了凸起条纹、肉粉色、肩臂伸长、静弦穿透和回程折角。当前是偏手办的原创测试造型，不宣称最终绒毛精修。

实际参考见[动作/资产对照](research/blender-guitar-v1-references.md)与[网页交互源码](research/blender-web-input-references.md)。尤其参考FretDance的琴面标定与接触/拨过/空档回位分段；其人类角色场景未直接采用。CatPilot虽为CC0可下载，实际造型和旧版2.77工程不适合直接替换Miao；BlenderStudio Cat需要严格3.6且登录，与当前5.2.3不即插即用。

24帧640×640已渲染，WebP图集618,476字节（解码约37.5MiB）。上/前臂恒长IK误差小于1.6e-7，琴面间隙至少0.039场景单位；触弦小范围重叠不等于完整物理仿真。0/23端点最大RGB差1/255、平均通道差小于0.00004。

真实浏览器按住ASDF各500ms：只录4次且画面4次触弦，停手归位。导出3.729秒H.264+AAC、720×880视频；223个实际编码帧中识别4次接触，各保留4/4/5/4帧。150ms演示8声/6可见接触、2次合并，说明仍是有界测试，不宣传高速逐音动画全对应。98项回归通过；发布验收完成后补发布记录。
