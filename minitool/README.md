复用现有完整橘猫图、FreePats CC0钢琴小样、内置谱与真人录音格式。保持独立站`public/`完整多乐器版本；此目录只构建小红书离线候选。

候选范围：八白键分两排、小星星／欢乐颂四事件手动谱页、听当前页、60秒／512次真人记录、回放、当前／上一遍恢复、600×800演奏小卡。图片明确不带声音，前24音截取有说明。无账户、网络、互跳、站外QR、网页文件下载、JSON导入、系统全屏、麦克风或视频编码。

## 构建与验证

先从当前Creator纯开发口令下载并读取当期官方`minitool-zip-builder`，本轮实读为1.8.0，安装在`.codex/skills/minitool-zip-builder`（本地，不入库）。更新版本时重新核对在线契约。构建需要Node、Python3和macOS `sips`；没有运行时新依赖。

```sh
npm run build:xhs
node --test scripts/minitool.test.mjs
```

输出：`artifacts/mobile-xhs-20261103/package/`、带buildID的ZIP、`build-audit.json`。ZIP时间戳规范化；相同运行文件可重建相同ZIP。`body[data-build]`绑定运行文件摘要，避免用旧预览充当新候选验收。所有包内资源按显式清单提供，不带开发配置。普通浏览器/JSDOM只用于调试和回归，不能代替平台模拟器与Android／iOS真机。最终源码按ES2017／Chrome61基线编写，CSS保留基础回退；Android8.1／Chrome61及iOS真机兼容性未实测。

- 钢琴adapter来自2026-11-02历史三键探针，扩到八白键；沿用现有校准、master/compressor、每键3／全局12声音上限与采样±1半音范围。这个轻量播放实现不是完整smplr Sampler。NOTICES包含公式来源的MIT全文及CC0样本来源。
